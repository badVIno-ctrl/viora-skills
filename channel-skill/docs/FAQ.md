# Частые вопросы

## Это бот для автопостинга?

Нет. Это набор правил и скриптов для ИИ-агента. Агент пишет и проверяет, публикует автор.
Режим по умолчанию отдаёт черновик человеку.

## Нужен ли Телеграм, чтобы попробовать?

Нет. Интервью, письмо, линтеры и оценка работают без ключей. Мост с Телеграмом это дополнение
для тех, кому удобно выдавать задачи с телефона.

## Нужен ли платный API модели?

Нет, если ты уже работаешь в агенте вроде Claude Code, Codex или Cursor: модель уже там.
Отдельный скрипт для своего провайдера есть, но он необязателен.

## Можно писать не по-русски?

Да. Поставь `brand.language` в нужный код и сделай свои рубрики. Готовый английский шаблон:
`profile/profiles/en-creator-telegram.json`. Сами инструкции для модели остаются на русском.

## А если мой канал не про технологии?

Работает для любой темы: кино, фитнес, еда, наука, местные новости. Темы и аудитория
берутся из профиля, а рубрики можно пересобрать под себя: [CUSTOMIZE.md](CUSTOMIZE.md).

## Где лежит мой профиль и попадёт ли он в гит?

Файл живёт в папке profile внутри скилла и в гит не попадает: он закрыт в gitignore.
Полное описание полей: [PROFILE.md](PROFILE.md).

## Скилл говорит про демо-профиль. Это ошибка?

Нет, это предупреждение: интервью ещё не пройдено и в работе данные DEMO STUDIO.
Запусти `python3 tools/onboard.py`, иначе в постах будут чужие ссылки.

## Как пересобрать профиль с нуля?

```bash
python3 tools/onboard.py --force
```

Точечная правка руками тоже легальна: поменял файл, потом `--render`.

## Агент всё равно ставит длинные тире

Проверь ответ и черновик:

```bash
python3 tools/lint_chat.py --text "твой ответ"
python3 tools/lint_post.py draft.txt --strict
```

Если модель упорная, добавь правило ноль в самое начало своего системного промпта:
готовая выжимка лежит в `PROMPT-CORE.txt`.

## Можно вставить скилл в свой проект?

```bash
python3 tools/install.py --target /путь/до/проекта --dry-run
python3 tools/install.py --target /путь/до/проекта
```

Чужие скиллы в папках обнаружения не трогаются.

## На чём работает ресерч и разбор видео?

Ресерч идёт через поиск агента или встроенные инструменты среды. Видео разбирается по субтитрам
через yt-dlp, если он установлен. Оба блока необязательны.

## Почему в ответе валидатора три предупреждения?

В чистом репозитории нет папок обнаружения: они появляются после команды install
и специально закрыты в gitignore, чтобы не держать в гите две копии одного скилла.
Это норма, ошибка была бы с префиксом E.

## Как понять, что ничего не сломалось после моих правок?

```bash
bash tools/check_all.sh
```

Ответ должен быть: всё чисто. Та же команда стоит в CI.

## Можно ли использовать коммерчески?

Да, лицензия MIT. Можно вести клиентские каналы и менять всё под себя.
