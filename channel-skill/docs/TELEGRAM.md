# Подключение Телеграма: свои ключи, свой канал

Мост с Телеграмом необязателен. Скилл пишет посты и без него: готовый
текст можно скопировать руками. Мост нужен, если хочется управлять
всем из Избранного: кинул тему себе в чат, получил черновик, одобрил,
пост ушёл в канал в твоё окно выхода.

В поставке нет ни одного чужого ключа. Каждый автор подключает свой
аккаунт и свой канал.

## Шаг 1. Свои ключи

1. Открой my.telegram.org и войди по номеру.
2. Раздел API development tools, создай приложение с любым именем.
3. Забери два значения: `api_id` и `api_hash`.

Это личные данные, один раз на аккаунт. В чат модели их не несут.

## Шаг 2. Файл с ключами

```
cp secrets/telegram.env.example secrets/telegram.env
```

Открой копию и вставь свои значения. Файлы `secrets/*.env` закрыты
в `.gitignore`: в гит они не попадут. Если держишь секреты в другом месте:

```
export CHANNEL_SECRETS=/путь/к/папке
```

## Шаг 3. Вход

```
python3 channel-skill/tools/tg.py setup
python3 channel-skill/tools/tg.py login
python3 channel-skill/tools/tg.py doctor
```

- `setup` ставит библиотеку telethon и готовит папки;
- `login` спрашивает номер и код из Телеграма в терминале и сохраняет
  строку сессии в твой файл;
- `doctor` показывает, что найдено и чего не хватает.

Код из СМС вводится только в терминале. Модель его не спрашивает никогда.

## Шаг 4. Настроить канал и режим

Канал, окно выхода и часовой пояс мост берёт из профиля автора, то есть
из ответов интервью. Посмотреть и поменять рабочие настройки моста:

```
python3 channel-skill/tools/tg.py config
```

Три режима:

| Режим | Что делает | Когда включать |
| --- | --- | --- |
| `draft` | готовит черновик в Избранном, в канал не пишет | всегда на старте |
| `scheduled` | ставит отложенный пост в окно выхода | когда доверяешь текстам |
| `auto` | публикует сам после проверок | только осознанно |

Смена режима живёт в профиле, поле `telegram.mode`.

## Шаг 5. Как идёт работа

1. В Избранном пишешь заявку с префиксом: `/post гайд про свет`.
2. Скилл забирает заявку: `tg.py poll` или сторож в фоне.
3. Пост собирается и прогоняется через линтер и оценку.
4. `tg.py stage` отдаёт черновик тебе в Избранное.
5. Одобрил: `tg.py publish`. Не одобрил: `tg.py cancel`.
6. `tg.py status` показывает, что в работе, `tg.py when` время следующего выхода.

Карточка всех команд автора: `python3 channel-skill/tools/tg.py card`.

## Сторож Избранного

Сторож смотрит только твои сообщения с префиксом и ничего не публикует сам.

```
bash start-watch.sh
```

На Windows: `powershell -ExecutionPolicy Bypass -File start-watch.ps1`.
Ручной запуск: `python3 channel-skill/tools/tg_watch.py`.

## Безопасность

- Строка сессии равна полному доступу к аккаунту. Не пересылай её никому.
- Не коммить `secrets/*.env`. Перед первым пушем проверь `git status`.
- Сеансы видны в Телеграме: Настройки, Устройства. Лишние завершай.
- Если ключ утёк: смени `api_hash` на my.telegram.org и заверши сеансы.
- Первые дни держи `draft`. Публикация без просмотра это риск автора.

## Если не работает

| Симптом | Причина и что делать |
| --- | --- |
| нет модуля telethon | `python3 channel-skill/tools/tg.py setup` |
| пишет про пустые ключи | проверь `secrets/telegram.env` и `CHANNEL_SECRETS` |
| не видит канал | в профиле пустое `channel.handle`, пройди интервью |
| заявки не ловятся | префикс должен совпадать с `telegram.prefixes` |
| пост ушёл не вовремя | окно и пояс берутся из профиля, проверь `channel.window` |

Диагностика одной командой: `python3 channel-skill/tools/tg.py doctor`.
