# Как устроен скилл

Коротко: один источник правды про автора, один источник правды про правила,
детерминированные проверки поверх. Модель пишет, скрипты судят, человек публикует.

## Цепочка данных

```
интервью (tools/onboard.py)
        ↓
профиль автора (profile/, JSON по схеме)
        ↓
читалка профиля (tools/profile.py)
        ↓
───┬──────────┬───────────┬─────────────┬───────────────
   тексты     линтеры      оценка        мост с Телеграмом
  (reference/) (lint_*.py)  (score_post.py)   (tg.py, tg_watch.py)
        ↓
готовый черновик → автор нажимает публикацию
```

## Три слоя

### 1. Профиль: кто пишет

Всё, что зависит от конкретного автора, лежит в одном JSON: имя, тон, темы, аудитория,
ссылки, рубрики, цифры канала, настройки Телеграма. Скрипты не знают ниодного имени
напрямую: они спрашивают `tools/profile.py`.

Файлы слоя: `tools/onboard.py` собирает, `tools/profile.py` читает и валидирует,
`profile/profile.schema.json` описывает структуру, `profile/profile.example.json` даёт демо-данные,
чтобы скилл запускался сразу после распаковки.

Почему так: без этого слоя скилл был бы привязан к одному каналу. Разделение позволяет
отдать его любому автору и не менять ни строки кода.

### 2. Знание: как писать

Текстовые правила лежат в справочниках: голос, крючок, вёрстка, разрез, борьба с ИИ-признаками,
форматы, рост, SEO. Порядок чтения задаёт `ROUTER.md`: на одну задачу один файл, не больше.

Три тира на разные модели:

| Тир | Что читает | Кому |
| --- | --- | --- |
| Карточка | `QUICKCARD.txt` | быстрые и слабые модели |
| Правила | `SKILL.md` плюс один справочник | рабочая норма |
| Полный | `PROMPT-FULL.txt` | аудит и спорные случаи |

Промпты не пишутся руками дважды. `tools/build_prompt.py` собирает `PROMPT-CORE.txt` и
`PROMPT-FULL.txt` из помеченных блоков в исходных файлах, а `--check` падает, если копия
разошлась с источником.

### 3. Проверки: что считается готовым

Субъективные оценки плохо работают, поэтому всё проверяемое проверяют скрипты:

| Скрипт | За что отвечает |
| --- | --- |
| `tools/lint_post.py` | футер, ссылки, хэштеги, запретные символы и штампы |
| `tools/lint_article.py` | статья на telegra.ph: заголовок, длина, подпись |
| `tools/lint_chat.py` | ответ агента в чате, тот же запрет на длинные тире |
| `tools/score_post.py` | балл по коридорам рубрики и цифрам канала |
| `tools/split_post.py` | разрез на пост и статью, лимиты Телеграма |
| `tools/validate_skill.py` | целостность самого скилла: версии, ссылки, футеры |
| `tools/run_evals.py` | эталоны поведения из `evals/cases.json` |
| `tools/check_all.sh` | всё выше одной командой |

У каждого скрипта есть свой самотест: `python3 tools/lint_post.py --selftest`. Самотесты не требуют
сети и не читают живой профиль: они специально переключаются на демо-данные,
чтобы результат не зависел от того, кто запустил.

## Мост с Телеграмом

`tools/tg.py` это одноразовые команды (вход, диагностика, отправка, статус),
`tools/tg_watch.py` это сторож, который смотрит твоё Избранное и ставит задачи в очередь.
Режим по умолчанию draft: ничего не улетает в канал без человека.
Ключи и строка сессии берутся из переменных среды или из папки secrets, в гит они не попадают.

## Память канала

Папка memory держит то, что нельзя вывести из профиля: уже использованные приветствия,
прошлые темы, принятые решения, фактические цифры по постам. `tools/memory.py` проверяет
приветствие на повтор и ведёт журнал.

## Поставка

`tools/install.py` кладёт копию скилла в папки обнаружения чужого проекта,
`tools/package.py` собирает архив для раздачи и проверяет состав через `--check`.

## Решения и причины

| Решение | Почему |
| --- | --- |
| Нуль внешних зависимостей в ядре | скилл должен запускаться сразу, без pip |
| Профиль в JSON, а не в коде | автор правит свои данные без страха сломать логику |
| Правила в тексте, проверки в коде | модель читает текст, но судит детерминизм |
| Один файл на задачу | больше контекста не значит лучше текст |
| Режим draft по умолчанию | публикация это ответственность человека |
| Запрет на длинное тире | самый заметный след модели, дешёво ловится машиной |
