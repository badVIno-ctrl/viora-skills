# Профиль автора: все поля

Профиль главный файл всего скилла. Имя автора, имя канала, голос, рубрики, коридоры длины,
футер и цифры канала живут здесь, а не в текстах скилла. Поменял профиль, поменялся весь скилл.

Где лежит: `channel-skill/profile/profile.json`. Этого файла нет в репозитории и он в .gitignore:
у каждого автора он свой.

Собрать его руками не надо. Пройди интервью:

```bash
cd channel-skill
python3 tools/onboard.py
```

Этот файл нужен, когда хочется поправить одно поле руками или понять, на что оно влияет.

## Три команды на всю жизнь

```bash
python3 tools/profile.py --show    # карточка профиля человечески
python3 tools/profile.py --check   # проверка полей и понятные ошибки
python3 tools/profile.py --who     # одна строка: кто автор и какой канал
```

Ещё есть `--json`, `--footer`, `--path` и `--selftest`.

## Как устроен файл

Обычный JSON в UTF-8. Полей много, но обязательных мало: всё остальное берётся из умолчаний.
Готовый пример целиком: `profile/profile.example.json`.
Формальная схема для редактора: `profile/profile.schema.json`.

Два шаблона на старт: `profile/profiles/ru-tech-telegram.json` и `profile/profiles/en-creator-telegram.json`.

## brand: кто ты

| Поле | Тип | Зачем |
| --- | --- | --- |
| `name` | строка, обязательно | Имя канала или бренда. Видно в подписях и в служебных сообщениях |
| `short` | строка | Короткое имя для тесных мест. Нет, возьмётся первое слово из name |
| `author` | строка, обязательно | Ник или имя. Скилл пишет от этого человека |
| `language` | ru, en и так далее | Язык постов. По умолчанию ru |
| `tone` | строка, обязательно | Голос в трёх словах, например нашёл, проверил, принёс |
| `audience` | строка, обязательно | Для кого пишем и в какой обстановке читают |
| `topics` | список строк | Темы канала. Из них собираются идеи и проверка на оффтоп |
| `about` | строка | Чем автор занимается. Даёт живые детали в тексте |
| `taboo` | список строк | Темы, которые не трогаем никогда |

## channel: куда выходит текст

| Поле | Тип | Зачем |
| --- | --- | --- |
| `platform` | telegram или other | Пока все форматы заточены под телеграм |
| `handle` | `@имя_канала` | Проверяется шаблоном: латиница, цифры и подчёркивание, 4-32 знака |
| `url` | ссылка | Полный адрес канала. Пусто, соберётся из handle |
| `window` | `16:30-21:00` | Окно публикации. Скилл предлагает время внутри этого окна |
| `tz` | зона IANA | Например Europe/Moscow или Europe/Berlin |

## links и footer: подвал поста

`links` это список пар в том порядке, в каком они стоят в футере:

```json
"links": [
  {"label": "ЧАТ", "url": "https://t.me/your_chat"},
  {"label": "GITHUB", "url": "https://github.com/your-name"}
]
```

Ярлык капсом и до 12 знаков. Ссылка обязана начинаться с http или https.

| Поле | Тип | Зачем |
| --- | --- | --- |
| `footer.enabled` | true или false | Нужен ли футер вообще |
| `footer.template` | строка | Свой футер знак в знак. Пусто, соберётся из links |
| `footer.legacy_labels` | список строк | Старые ярлыки вроде `[V.S.](`. Линтер ловит их в старых черновиках |

Проверить, как выглядит футер: `python3 tools/profile.py --footer`.

## article: длинный текст

| Поле | Тип | Зачем |
| --- | --- | --- |
| `article.enabled` | true или false | Разрешать ли связку пост плюс статья |
| `article.platform` | строка | По умолчанию telegra.ph |
| `article.signature` | строка | Подпись в конце статьи |

## second_brand: вторая площадка

Отдельный мемный или лёгкий канал того же автора. Подробности в `reference/second-brand.md`.

| Поле | Тип | Зачем |
| --- | --- | --- |
| `second_brand.enabled` | true или false | Выключено, рубрика просто не появляется |
| `second_brand.name` | строка | Имя второй площадки |
| `second_brand.tag` | строка | Какая рубрика её обслуживает, например мем |
| `second_brand.min` и `max` | числа | Коридор длины подписи |
| `second_brand.footer` | true или false | Нужен ли там обычный футер |

## rubrics: только отличия от умолчаний

В скилле есть готовый набор рубрик с каркасами и коридорами. В профиле пишем только то,
что отличается. Пустой объект значит взять всё как есть.

```json
"rubrics": {
  "гайд": {"min": 900, "max": 1800},
  "реклама": null,
  "обзор": {"min": 400, "max": 800, "points": [3, 5], "frame": "PAS"}
}
```

- Объект с полями накладывается поверх умолчания.
- `null`, `false`, `"off"` или `"нет"` выключают рубрику насовсем.
- Новое имя создаёт свою рубрику.

Поля строки рубрики: `min`, `max` (коридор знаков), `points` (сколько пунктов в теле),
`frame` и `frame_alt` (каркасы вроде AIDA или PAS), `forward` (required, wanted или none),
`file` (какой файл из reference читать), `soft_first_screen` (мягкий первый экран).

Свой итоговый набор всегда виден в `python3 tools/profile.py --show`.

## voice: добавки к голосу

| Поле | Тип | Зачем |
| --- | --- | --- |
| `voice.greeting_max_words` | число | Потолок слов в приветствии, по умолчанию 5 |
| `voice.extra_banned` | список слов | Личный стоп-лист сверх общего |
| `voice.extra_lexicon` | список слов | Свои словечки, которые линтер не трогает |

## metrics: цифры канала

```json
"metrics": {"subscribers": 260, "reach": [165, 386], "reactions": [1, 5]}
```

Оценка поста считается от этих чисел, а не от чужих. Если канал только стартует, ставь нули:
скилл просто не будет ссылаться на охват.

## telegram: мост с Избранным

| Поле | Тип | Зачем |
| --- | --- | --- |
| `telegram.prefixes` | список строк | Команды в Избранном, на которые отвечает сторож |
| `telegram.mode` | draft, scheduled или auto | Что делать с готовым текстом |
| `telegram.inbox` | строка | Куда класть черновик, по умолчанию me |

Ключи и сессия в профиле не хранятся никогда. Они живут в `secrets/telegram.env`,
а подключение описано в `docs/TELEGRAM.md`.

## Частые ошибки проверки

| Что говорит --check | Что делать |
| --- | --- |
| нет brand.name, brand.author, brand.tone или brand.audience | Заполнить: без этого голоса нет |
| channel.handle должен быть вида @имя_канала | Убрать ссылку целиком, оставить хэндл |
| channel.window должен быть вида 16:30-21:00 | Два времени через дефис |
| ярлык ссылки не годится | Капс, до 12 знаков, без эмодзи |
| футер включён, но ссылок нет | Заполнить links или footer.template |
| в профиле длинное тире | Заменить на обычный дефис |
| не осталось ни одной рубрики | Вернуть хотя бы одну |
| коридор знаков задан наоборот | min меньше max |
| telegram.mode должен быть draft, scheduled или auto | Починить значение |

## Как поменять профиль позже

Переименовался, сменил тему, добавил ссылку:

```bash
cd channel-skill
python3 tools/onboard.py --force    # пройти интервью заново
python3 tools/onboard.py --render   # просто пересобрать тексты под новый профиль
```

`--render` нужен всегда, когда правишь JSON руками: он разносит новые данные
по карточке, справочникам и памяти канала.
