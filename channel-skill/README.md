# CHANNEL SKILL

**Скилл для ИИ-агента, который пишет посты в твой телеграм-канал твоим голосом.**

Сначала задаёт вопросы про тебя и канал, потом пишет. Не наоборот.

MIT · версия 6.1.0 · python 3.8+ · нуль внешних зависимостей

[Быстрый старт](docs/GUIDE.md) · [Интервью](channel-skill/ONBOARDING.md) · [Профиль](docs/GUIDE.md) · [Телеграм](docs/GUIDE.md) · [Устройство](docs/GUIDE.md) · [FAQ](docs/GUIDE.md) · [English](README.en.md)

## В чём боль

Любая модель умеет написать пост. Проблема в том, что пост получается не твой: длинные тире,
«в современном мире», выдуманные цифры, чужой тон, разные подвалы в каждом посте и стена текста
там, где в телеграме нужен разрез.

CHANNEL SKILL закрывает всю цепочку: узнать автора, выбрать рубрику и каркас, написать,
прогнать через линтеры, поставить оценку на цифрах твоего канала и отдать готовый текст.
Публикует всё равно человек.

## Главное отличие: скилл спрашивает первым

Первый запуск это не текст, а короткое интервью на 5-7 минут: кто ты, про что канал,
для кого пишешь, какой у тебя тон, какие рубрики, какие ссылки стоят в подвале.
Ответы складываются в профиль, и весь скилл начинает говорить твоим голосом.

```bash
cd channel-skill
python3 tools/onboard.py
```

Интервью проходится тремя способами:

| Способ | Команда | Когда удобно |
| --- | --- | --- |
| В терминале, вопрос за вопросом | `python3 tools/onboard.py` | Ставишь себе сам |
| Агент спрашивает в чате | `python3 tools/onboard.py --questions`, потом `--stdin` | Claude Code, Codex, Cursor |
| Готовый шаблон и правка руками | файл из `channel-skill/profile/profiles` | Надо очень быстро |

Дальше всё берётся из профиля: имя канала, тон, рубрики и их коридоры длины, футер,
окно публикации и цифры канала для оценки. Описание всех полей: [docs/GUIDE.md](docs/GUIDE.md).

## Три минуты до первого поста

```bash
git clone https://github.com/OWNER/channel-skill.git
cd channel-skill/channel-skill

python3 tools/onboard.py          # 1. интервью про автора и канал
python3 tools/profile.py --check   # 2. проверить, что профиль собран

# 3. попросить агента: сделай пост про такое-то в такой-то рубрике
python3 tools/channel.py ship draft.txt --rubric гайд   # 4. одна команда на всю проверку
```

`ship` это автоправка, линтер, оценка и разрез длинного текста за один ход.
Подробнее: [docs/GUIDE.md](docs/GUIDE.md).

## Что умеет

| Блок | Что делает |
| --- | --- |
| Интервью | Собирает профиль автора и разносит его по всем файлам скилла |
| Маршрутизация | По задаче выбирает рубрику, каркас, коридор длины и один файл на чтение |
| Линтер поста | Ловит голые ссылки, чужой футер, потерянный хэштег и ИИ-признаки |
| Автоправка | Чинит то, что чинится механически, остальное показывает списком |
| Оценка | Ставит балл от охвата и реакций именно твоего канала |
| Разрез | Длинный текст режет на пост плюс статью на telegra.ph |
| Ресерч и видео | Ищет факты и разбирает видео по субтитрам без платных ключей |
| Память канала | Помнит прошлые приветствия, темы и решения, чтобы не повторяться |
| Мост с Телеграмом | Задача из Избранного, черновик туда же. На твоих ключах |

## Правило ноль

Длинного тире нет нигде: ни в постах, ни в статьях, ни в ответах агента в чате.
Это самый заметный след модели в тексте, поэтому у него отдельное правило, отдельный линтер
и отдельная проверка всего репозитория.

## С какими агентами работает

Любой агент, который читает файлы и запускает python3:

- Claude Code и любая среда с Agent Skills: `.claude-plugin/plugin.json` и `CLAUDE.md`.
- Codex: `.codex-plugin/plugin.json` и `AGENTS.md`.
- Cursor: корневой файл правил и `.cursor/rules/channel-skill.mdc`.
- Gemini и прочие: `GEMINI.md`.
- Среда без файлов: вставь `channel-skill/PROMPT-CORE.txt` в первое сообщение.

Слабым и быстрым моделям достаточно одной карточки `channel-skill/QUICKCARD.txt`,
а большим и аккуратным есть `channel-skill/SKILL.md` и роутер `channel-skill/ROUTER.md`.

## Установка в свой проект

```bash
cd channel-skill
python3 tools/install.py --target /путь/до/проекта --dry-run
python3 tools/install.py --target /путь/до/проекта
```

Копия скилла ляжет в `.claude/skills`, `.agents/skills` и `.cursor/skills`. Чужие скиллы в этих
папках не трогаются. Собрать архив для раздачи: `python3 tools/package.py`.

## Свой Телеграм, свои ключи

Мост с Телеграмом необязателен: скилл работает и без него. Если включить, получается так:
пишешь задачу себе в Избранное, туда же возвращается готовый черновик.

```bash
cp secrets/telegram.env.example secrets/telegram.env   # свой api_id и api_hash с my.telegram.org
python3 channel-skill/tools/tg.py setup
python3 channel-skill/tools/tg.py doctor
```

В репозитории нет ни одного чужого ключа и ни одного токена. Всё, что лежит в `secrets`,
это шаблоны с расширением example, а живые файлы закрыты в gitignore.
Шаги с картинками и разбор ошибок: [docs/GUIDE.md](docs/GUIDE.md).

## Безопасность в трёх строках

- Скилл ничего не публикует сам: режим по умолчанию отдаёт черновик человеку.
- Ключи и сессия живут только у тебя на машине, в профиле их нет никогда.
- Выдуманные цифры и ссылки запрещены правилами скилла: нет в сырье, агент спрашивает.

Подробно: [docs/GUIDE.md](docs/GUIDE.md).

## Какое качество считается приемлемым

В скилле есть свой прогон проверок: самотесты всех скриптов, эталоны поведения,
сборка промптов из одного источника, проверка состава поставки и поиск длинных тире.

```bash
cd channel-skill
bash tools/check_all.sh
```

Ответ должен быть одной строкой: всё чисто. Та же команда стоит в CI на каждый пуш.

## Структура репозитория

```
.
├─ channel-skill/          сам скилл
│  ├─ SKILL.md            правила и пайплайн
│  ├─ QUICKCARD.txt       одна карточка для слабых моделей
│  ├─ ROUTER.md           что читать под какую задачу
│  ├─ ONBOARDING.md       сценарий интервью
│  ├─ profile/            профиль автора, схема и шаблоны
│  ├─ reference/          справочники по форматам и голосу
│  ├─ memory/             память канала
│  ├─ evals/              эталоны поведения
│  └─ tools/              скрипты: интервью, линтеры, оценка, мост с Телеграмом
├─ docs/                  документация для людей
├─ secrets/               шаблоны env, живые ключи в gitignore
├─ hooks/                 проверка среды при старте сессии
└─ start-watch.sh         смена в Телеграме одной командой
```

## Требования

python3 версии 3.8 и выше. Всё остальное стандартная библиотека. Для моста с Телеграмом
нужен пакет telethon, для разбора видео по субтитрам yt-dlp. Оба необязательны.
