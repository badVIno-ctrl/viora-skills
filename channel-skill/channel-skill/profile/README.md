# Профиль автора

Здесь живёт вся личная часть скилла: имя бренда, голос, рубрики, ссылки,
окно выхода, цифры канала. Инструменты читают профиль и подстраиваются
сами: в коде нет ни одного чужого бренда.

## Файлы

| Файл | Зачем |
| --- | --- |
| `profile.example.json` | демо-профиль поставки, чтобы скилл работал сразу |
| `profile.schema.json` | схема полей для редактора и проверки |
| `profiles/` | готовые шаблоны под типичные каналы |
| profile.json | твой профиль. Собирается интервью, в гит не попадает |

Демо-профиль нужен только для тестов и первого знакомства. Публиковать посты
с его ссылками нельзя: они вымышленные.

## Как завести свой профиль

Самый короткий путь: попроси модель провести интервью. Порядок вопросов
и правила описаны в `ONBOARDING.md`.

В терминале:

```
python3 tools/onboard.py               # интервью вопрос за вопросом
python3 tools/onboard.py --check       # код 1, если профиля нет или он демовый
python3 tools/profile.py --show        # что сейчас в профиле
python3 tools/onboard.py --render      # применить правки ко всем текстам
```

Готовые шаблоны:

```
python3 tools/onboard.py --from-json profile/profiles/ru-tech-telegram.json
python3 tools/onboard.py --from-json profile/profiles/en-creator-telegram.json
```

Поверх готового профиля пишет только `--force`.

## Поля, которые важнее всего

- `brand.name`, `brand.author`: имя канала и подпись автора.
- `brand.tone`: три глагола про то, что ты делаешь. Из них растёт голос.
- `brand.audience`: для кого пишешь и в какой обстановке читают.
- `brand.taboo`: темы, которые скилл обязан обходить.
- `channel.handle`, `channel.window`, `channel.tz`: куда и когда выходит.
- `links` и `footer.enabled`: хвост поста. Футер можно выключить совсем.
- `rubrics`: коридоры знаков и рамки по рубрикам.
- `metrics`: подписчики и охваты, нужны для трезвой оценки поста.
- `telegram`: префиксы заявок и режим публикации: `draft`, `scheduled`, `auto`.

## Рубрики

Значения по умолчанию уже есть: в `rubrics` лежат только правки.

```json
"rubrics": {
  "гайд": {"min": 900, "max": 2000},
  "реклама": null,
  "обзор": {
    "min": 400,
    "max": 800,
    "points": [3, 5],
    "forward": "required",
    "frame": "SLAY",
    "frame_alt": "BAB",
    "file": "reference/formats.md"
  }
}
```

- `null` убирает рубрику совсем;
- `min` и `max` задают коридор знаков;
- `points` сколько пунктов ждём в теле;
- `forward` одно из `required`, `wanted`, `none`;
- `frame` и `frame_alt` рамки подачи: SLAY, PAS, AIDA, BAB, STAR;
- `file` куда скилл идёт за образцами.

После любой ручной правки вызови проверку и пересборку:

```
python3 tools/profile.py --check
python3 tools/onboard.py --render
```
