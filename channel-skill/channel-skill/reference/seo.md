# SEO и виральность

В Telegram нет поисковой выдачи как в вебе. Зато есть три других канала трафика:
внутренний поиск по сообщениям, пересылки и статьи на telegra.ph, которые видит веб-поиск.
Работаем по всем трём.

## Канал 1: внутренний поиск Telegram

Люди ищут в Telegram так же, как в браузере: вбивают название сервиса.
Поиск идёт по тексту сообщения, не по скрытым тегам и не по тексту ссылки.

Правила:

1. Название сервиса пишем ЛАТИНИЦЕЙ так, как в оригинале: Screenpipe, а не Скринпайп.
2. Название обязательно в ТЕКСТЕ, а не только в ссылке. Ярлык ТЫК поиск не найдёт.
3. Русский синоним рядом один раз: «Screenpipe, запись экрана локально».
4. Один хэштег-рубрика. Он работает как папка внутри канала, по нему листают архив.

## Канал 2: пересылки

Охват в Telegram растёт почти только пересылками. Алгоритма рекомендаций нет,
значит каждый новый читатель пришёл потому, что кто-то нажал «переслать».

Три вещи, которые реально повышают пересылки:

1. ЦИФРА ВЫГОДЫ в первых 100 знаках. Сколько денег или времени сэкономит читатель.
2. АДРЕСНОСТЬ концовки. Не «делись», а «перешли тому, кто ещё платит».
3. СРОК. Закрывающаяся дверь даёт пересылку быстрее любой пользы без срока.

Факты по своему каналу лежат в `memory/metrics.md`. Смотреть туда перед спором о формате.

## Канал 3: статья на telegra.ph видна поисковикам

Страницы telegra.ph индексируются и могут приводить людей годами. Это единственное
место, где классическое SEO работает напрямую.

| Где | Что делаем |
|---|---|
| Заголовок статьи | ключ плюс цифра плюс год, 40-70 знаков, цель 50-55 |
| Первые 200 знаков | ключ повторяется один раз естественно |
| Подзаголовки | названия сервисов латиницей, это готовые ключи |
| Адрес страницы | собирается из заголовка, поэтому ключ ОБЯЗАН быть в заголовке |
| Ссылки внутри | одна на канал, одна на старый пост по теме |
| Длина | 3000-6000 знаков |

### Заголовок: коридор 40-70, цель 50-55 знаков

Целимся в 50-55 знаков. Причина простая: в выдаче поиска и в превью ссылки видно
около 55 знаков, дальше строка обрывается. Всё, что за обрывом, для читателя
не существует, поэтому цифра не должна стоять в хвосте.

1. Ключ в первых 30 знаках, не в конце.
2. Цифра и год обязательны, они сами по себе ключ.
3. Вместо длинной связки двоеточие: «7 абузов 2026: без карты и VPN».
4. Никаких «полный обзор» и «всё, что нужно знать»: знаки без пользы.

Считать знаки руками не надо:

```bash
python3 -c "print(len('7 рабочих абузов на сентябрь 2026 без карты'))"
```

### Первый абзац отвечает сразу, 40-60 слов

Первые 40-60 слов это ответ, а не подводка. Поисковик берёт этот абзац в блок
ответа, человек по нему решает, читать ли дальше. Подводка убивает оба сценария.

Порядок внутри абзаца: ответ, цифра, кому это нужно, что будет дальше.

Пример на 47 слов: «Notion Business берётся бесплатно на год через образовательную
заявку. Проверил на двух аккаунтах: одобрили за сутки, карту не просили. Ниже
восемь шагов и то место, где заявку чаще всего отклоняют. Если аккаунт старше
года, шаг третий делаем по-другому, об этом отдельно.»

Три запрета для первого абзаца: нет вопроса читателю, нет истории «давно хотел
разобраться», нет обещания «в этой статье мы рассмотрим».

### Адрес страницы

telegra.ph собирает адрес из заголовка сам, но подчистить заголовок стоит заранее:
адрес это то, что видит поисковик и что человек перешлёт в чат.

| Правило | Как выглядит |
|---|---|
| Только латиница | abuzy, а не абузы |
| Ключ внутри адреса | abuzy-notion |
| Цифра и год | 7-abuzov-2026 |
| Стоп-слова выкидываем | без kak, i, dlya, na |
| Длина 3-6 слов | 7-abuzov-notion-2026 |
| Разделитель дефис | не подчёркивание |

Готовый адрес выглядит так: `telegra.ph/7-abuzov-notion-2026`. Дату telegra.ph
добавляет в хвост сам, её не трогаем и в заголовок не дублируем.

Подробности по рендеру и адресам в `reference/telegraph.md`.

## Канал 4: YouTube и закреп как вход в Telegram

Название канала: имя плюс тема, до 60 знаков, без капса. У DEMO это demo_author,
у второго бренда ВТОРОЙ БРЕНД это `@second-brand_V`.

Описание канала: первые две строки видны без раскрытия, туда идёт смысл канала
и ссылка на Telegram. Дальше ключевые слова темы обычным текстом.

Закреплённый комментарий это единственный вход из ролика в Telegram.
Замер 25.08.2026: шортс собрал 26 866 просмотров, 98,6 процента трафика пришло
из ленты Shorts, а подписчиков с него 2, потому что закрепа со ссылкой не было.
Разбор в `memory/decisions.md`, шаблоны закрепа в `reference/growth.md`.

Проверка перед выходом ролика:

1. Название до 60 знаков, ключ в начале, капса нет.
2. Первые две строки описания несут смысл и ссылку.
3. Закреплённый комментарий стоит, ссылка в нём рабочая.
4. Хэштегов 3-5, все по теме ролика.

## Как выбирать ключевое слово

Не выдумываем. Смотрим, как сам сервис себя называет, и как его ищут люди.
Одна команда даёт оба ответа:

```bash
python3 tools/research.py "Screenpipe что это лимиты бесплатно"
```

Формула ключа для рубрик: ЦИФРА + СУЩНОСТЬ + ГОД.

| Рубрика | Заголовок статьи |
|---|---|
| #сервисы | 15 бесплатных сервисов и реп для разработчика 2026 |
| #абуз | 7 рабочих абузов на сентябрь 2026 без карты |
| #гайд | Как подключить X бесплатно шаг за шагом 2026 |
| #релиз | Открыл исходники X, как запустить у себя |

## Слова, которые дают клик, и слова, которые его убивают

| Работает | Не работает |
|---|---|
| бесплатно, без карты, без VPN | уникальный, революционный |
| до 1 сентября, осталось два дня | в ближайшее время, скоро |
| проверил сам, у меня завелось | как известно, многие говорят |
| 3000 в месяц против нуля | выгодное предложение |
| где подводный камень | важно понимать, стоит отметить |

## Время публикации

Рабочее окно 16:30-21:00 по Europe/Moscow. Проверено на своём канале.

Пост после 23:00 теряет охват. Цифры 20.08.2026: пост в 22:52 собрал 165 просмотров,
пост в 23:34 только 116. Два поста ближе 40 минут друг к другу делят одну аудиторию.

## Проверка SEO перед отдачей

1. Есть ли название сервиса латиницей в тексте поста.
2. Есть ли цифра выгоды в первых 100 знаках.
3. Называет ли концовка конкретного человека для пересылки.
4. Один хэштег и он из списка рубрик.
5. Есть ли срок или цена для сравнения.
6. Если есть статья: ключ в заголовке и ссылка на неё видна до просьбы переслать.
7. Если материал уходит в шортс: закреплённый комментарий готов заранее.
