# Подбор слов

Это главный файл после `SKILL.md`. Структуру поста собрать легко, а выдаёт машину именно
выбор слов. Слабое слово убивает нормальный пост быстрее, чем кривая вёрстка.

## Один принцип

Каждое слово либо несёт факт, либо просто хвалит. Хвалит - выкидываем.

| Не так | Так |
|---|---|
| отличный сервис | не сыпется на длинных промптах |
| мощная модель | держит контекст в миллион |
| удобный интерфейс | всё в одном окне |
| быстрая генерация | картинка за 10 секунд |
| качественный результат | артефактов почти нет |
| большие лимиты | 5 млн токенов в день |
| выгодное предложение | полгода бесплатно |
| простая установка | два клика и готово |
| хорошо работает с русским | русский тянет без акцента |

Если факта под словом нет - слово не заменяем синонимом, а вычёркиваем целиком.

## Глаголы, которыми пишем шаги

Всегда мы-форма, всегда настоящее время: регаем, заходим, жмём, вводим, копируем, вставляем,
выбираем, качаем, врубаем, ставим, забираем, лутаем, чекаем, крутим, выдёргиваем, пересоздаём,
меняем, отключаем, проверяем.

| Не так | Так |
|---|---|
| необходимо зарегистрироваться | регаем акк |
| выполните авторизацию | заходим через Google |
| произведите установку приложения | качаем приложение |
| активируйте бесплатный тариф | врубаем бесплатный тариф |
| скопируйте API-ключ | копируем ключ |
| смените IP-адрес | меняем IP |
| осуществите проверку лимитов | чекаем лимиты во вкладке Usage |

## Как называем вещи

| Длинно и чужеродно | По-нашему |
|---|---|
| аккаунт | акк |
| регистрация | рега |
| реферальная ссылка | рефка |
| работает / не работает | робит / второй бренд |
| бесплатный доступ | халява |
| ограничения по использованию | лимиты |
| самое выгодное в подборке | самое жирное |
| полезная находка | годнота |
| дыра в системе оплаты | дырка |
| зарубежные сервисы и их подписки | буржуи |
| подписчики | сабы |
| топовые модели | опусы, топ-модели |

Англицизмы оставляем там, где так реально говорят: API, IDE, промпт, триал, инвайт, кредиты,
токены, бэкап, вайб-кодинг. Переводить их на русский не надо, будет деревянно.

## Цифры

- Пишем цифрами, не словами: `800 запросов`, а не `восемьсот запросов`.
- Крупные числа сокращаем: `5 млн токенов`, `300K кредитов`, `2.4 трлн параметров`.
- Деньги как в жизни: `18 долларов в месяц` или `$18/мес`. Одинаково в пределах поста.
- Срок всегда конкретный: `до 25 августа`, `5 дней`, `30 дней`. Не «ограниченное время».
- Цифра идёт в заголовок пункта, если она главная выгода.
- Ноль округлений в свою пользу. Написано 800 - пишем 800, а не «почти тысяча».

## Слова-паразиты

Реально, просто, буквально, очень, крайне, довольно, весьма, максимально, полностью.
Максимум один такой на пост. Обычно предложение без них становится только сильнее.

| Не так | Так |
|---|---|
| реально годная штука | годная штука |
| очень большие лимиты | лимиты на 5 млн токенов |
| буквально в два клика | в два клика |
| полностью бесплатно | бесплатно |

## Опасные слова

- **бесплатно** - только если правда бесплатно. Триал это не бесплатно, это триал.
- **навсегда, гарантированно, 100%** - не пишем никогда. Абузы живут неделями.
- **лучший, топ-1** - только если так сказал автор или есть источник.
- **все модели** - если знаем список, пишем список. Если нет, пишем «модели» без «все».
- **безопасно** - не наше слово. Про риски пишем в блоке `ВАЖНО!`.

## Как хвалим и как ругаем

Хвалим фактом и своим опытом:

- «Сижу на нём третий день, пока не падало.»
- «Из пяти генераций три годные.»
- «Дают больше, чем Cursor на бесплатке.»

Ругаем прямо, без обтекания:

- «Работает нестабильно, у меня завелось с третьего раза.»
- «Уже второй бренд, оставляю для истории.»
- «Интерфейс кривой, но лимиты того стоят.»

Никогда: «имеет как плюсы, так и минусы», «на любителя», «решать вам».

## Заголовок пункта

Формула: действие или выгода плюс цифра или срок. Название сервиса можно спрятать внутрь.

| Слабо | Сильно |
|---|---|
| Diagram Design | Делаем из Claude дизайнера инфографики |
| Flux 3 | Видеогенератор Flux 3 раздают до 17 августа |
| ZCode с моделью GLM | 5 млн токенов в день без карты |
| Новый сервис для музыки | Песни до 10 минут без лимитов |
| Про Notion Business | Notion Business на полгода БЕЗ КАРТЫ |

## Связки между блоками

Можно: «По факту:», «Как забрать:», «Что нужно делать:», «Я проверял:», «Из минусов:»,
«Дальше просто:», «Крч:».

Нельзя: «Итак», «Давайте разберёмся», «Стоит отметить», «Важно понимать», «Что это для нас
значит», «Комментарий от проверщика», «Подводя итог», «В заключение».

## Финальный проход по словам

Перечитай пост и на каждом предложении спроси три вещи:

1. Это слово несёт факт или просто хвалит?
2. Так говорит человек в переписке или так пишет пресс-релиз?
3. Можно сказать то же самое короче?

Если на любой вопрос ответ плохой - правь на месте, не жди конца текста.
