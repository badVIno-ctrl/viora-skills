# Второй бренд

Второй бренд это отдельная площадка того же автора: мемный канал, второй телеграм,
шортс-канал или лента на другом языке. Главный канал приносит пользу, второй приносит
узнавание. Человек смеётся, запоминает имя и приходит в главный канал сам: через закреп
и описание, а не через ссылку в кадре.

## Шаг ноль: включён ли он вообще

Второй бренд живёт в профиле автора, в блоке `second_brand`. Образец полей лежит
в `profile/profile.example.json`.

| Поле | Что значит |
|---|---|
| `enabled` | `false` и вся эта страница не применяется: второго бренда у автора нет |
| `name` | имя второго канала в текстах |
| `tag` | рубрика, которая отвечает за второй бренд: чаще всего мем или шортс |
| `min` и `max` | коридор знаков подписи для этой рубрики |
| `footer` | ставится ли футер главного канала под таким постом: по умолчанию нет |

Проверить и поменять: `python3 tools/profile.py --show` и `python3 tools/onboard.py --force`.
Если второй бренд выключен, никогда не предлагаем автору мемы и вторую ленту по своей воле.

## Голос: короче и злее, чем в главном канале

1. Одна шутка на пост. Второй панч убивает первый.
2. Шагов нет, слов «как забрать» нет. Мем ничего не выдаёт.
3. Блока ВАЖНО! нет: предупреждать не о чем, продавать нечего.
4. Приветствия нет. Первая строка это сразу удар.
5. Злее значит точнее, а не грубее. Бьём по ситуации, а не по человеку.
6. Ты-форма разрешена: мем говорит с одним человеком.
7. Контекст берём из тем автора. Шутка про чужую нишу не срабатывает.

## Восемь шаблонов мема

1. **Скрин работы.** Кадр из реального процесса и подпись, которая ломает ожидание.
2. **Диалог.** Просьба человека и ответ мимо задачи.
3. **Ожидание против реальности.** Два кадра: как задумал и что вышло.
4. **«Когда ...»** Строка с ситуацией, дальше реакция.
5. **Два стула.** Выбор между двумя одинаково плохими вариантами.
6. **График.** Линия, которая идёт не туда, куда обещали.
7. **Чат с заказчиком.** Короткая переписка, где просят невозможное.
8. **Баг как фича.** Поломка, объявленная задумкой.

Шаблон из прошлого поста не берём. Журнал: `memory/meme-log.md`.

```bash
python3 tools/memory.py check-meme "шутка одной строкой"
```

## Стоп-лист второго бренда

- Нет ссылок в кадре: ни в тексте на экране, ни в подписи.
- Нет офферов: ни подписки, ни промокода, ни просьбы.
- Нет политики и нет чужих табу из профиля автора.
- Нет личных нападок: ни имён, ни каналов, ни коллег по цеху.
- Нет двух шуток в одном посте.
- Нет футера главного канала, пока `second_brand.footer` не поставлен в `true`.

```bash
python3 tools/lint_post.py meme.txt --brand second-brand
```

Коды линтера на этот список: `E-MEME-LINK`, `E-BRAND-OFFER`, `E-BRAND-FOOTER`.

## Длина подписи

Коридор берётся из профиля: `second_brand.min` и `second_brand.max`. Типовое значение
40-220 знаков: строка хука, строка панча, хэштег рубрики.
Подпись длиннее значит шутку объясняют словами. Объяснённая шутка мертва:
режем до одной строки или меняем шаблон.

## Где стоит ссылка на главный канал

Ровно два места: закреплённый комментарий под постом и описание канала.
В кадре, в подписи и в озвучке ссылки нет.

Причина простая: виральный мем без закрепа даёт просмотры и не даёт подписчиков.
Свои цифры по таким постам автор ведёт в `memory/metrics.md`, решения в `memory/decisions.md`.

## Главный канал против второго

| Что | Главный канал | Второй бренд |
|---|---|---|
| Голос | тон из профиля | короче и злее |
| Длина | коридор рубрики | `second_brand.min` и `max` |
| Футер | обязателен и последний | нет по умолчанию |
| Хэштег | рубрика из списка | хэштег рубрики второго бренда |
| Оффер | обязателен в рекламных рубриках | нет |
| Концовка | просьба переслать | панч и тишина |
