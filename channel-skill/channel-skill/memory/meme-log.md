# Использованные шутки и шаблоны

Файл живой. После выхода мем-ролика дописываем строку вниз.
Формат: `ДАТА | шаблон | шутка одной строкой`

Правило: если шаблон стоял в прошлом ролике или шутка уже есть в этом списке,
не предлагаем её вообще. Восемь шаблонов лежат в `reference/second-brand.md`.

Проверка и запись идут теми же командами, что для приветствий:

```bash
python3 tools/memory.py check-meme "когда починил один баг"
python3 tools/memory.py add-meme "когда починил один баг" --template "когда"
```
