# Видео

Слабая модель: читай `channel-video/LITE.md` и всё. Этот файл для средней и сильной.

## Главный принцип: текст вместо картинки

Кадр видео это тысячи токенов. Секунда субтитров это единицы токенов.
Для поста в канал текста достаточно в 99 случаях из 100.

Поэтому `tools/watch.py` по умолчанию берёт только субтитры и ни одного кадра.
Кадры включаются только вручную и только когда без них не понять суть.

## Команды

| Задача | Команда |
|---|---|
| Понять, о чём видео | `python3 tools/watch.py "URL"` |
| Найти место по словам | `python3 tools/watch.py "URL" --find "цена,лимит"` |
| Полный текст без сжатия | `python3 tools/watch.py "URL" --full` |
| Только отрезок | `python3 tools/watch.py "URL" --start 04:10 --end 07:30` |
| Шире бюджет вывода | `python3 tools/watch.py "URL" --budget 4000` |
| Кадры для сильной модели | `python3 tools/watch.py "URL" --frames 6` |
| Машинный вывод | `python3 tools/watch.py "URL" --json` |
| Проверить окружение | `python3 tools/watch.py --doctor` |

Флаг `--frames` требует ffmpeg и скачивания видео. Слабой модели он запрещён.
Потолок 8 кадров. Больше скрипт не даст даже если попросить.

## Три уровня глубины

| Уровень | Что берёт | Когда |
|---|---|---|
| по умолчанию | субтитры, выжимка 1500 знаков | почти всегда |
| `--full` | весь текст с таймкодами | нужна точная цитата |
| `--frames N` | плюс N кадров | видео без речи, геометрия интерфейса, демо без комментариев |

## Как скрипт сжимает длинное видео

Сжатие детерминированное, без моделей и без ключей. Строится карта видео:

1. Первые 400 знаков целиком. В начале автор всегда говорит, о чём ролик.
2. Равномерные выдержки по всей длине с таймкодами.
3. Строки, где есть цифры, цены, проценты или слова из `--find`.
4. Последние 200 знаков. В конце часто лежит вывод.

Трёхчасовое видео так умещается в 1500 знаков без потери главного.

## Что брать из видео в пост

Видео это источник фактов, а не содержание поста. Берём три вещи:

1. Цифру или цену, которую назвали вслух.
2. Одну шероховатую деталь: что у автора не завелось или где он выругался.
3. Конкретный шаг, который можно повторить.

Пересказ видео поштучно в пост не идёт никогда. Это читается как кража и не даёт пересылок.

## Ссылка на видео в посте

Ярлык только `[ВИДЕО]`. На свой канал ярлык `[YOUTUBE]`.
Если видео чужое, в тексте обязательно видно, что оно не наше: «у них в ролике».
Ссылка на YouTube первой в сообщении даёт превью видео вместо превью статьи.
Если в посте есть статья на telegra.ph, ссылка на видео идёт ПОСЛЕ неё.

## Гигиена контекста

1. Один запуск на одно видео на один пост.
2. `--full` только когда нужна дословная цитата и видео короте 20 минут.
3. Не клади сырой текст субтитров в ответ автору. Только выводы списком.
4. Не включай `--frames` без прямой просьбы автора.

## Границы

Скачиваем только то, что отдаёт сам сервис по открытой ссылке.
Приватные и платные видео не трогаем, куки из браузера не таскаем.
Перезалив чужого видео в канал не предлагаем.
