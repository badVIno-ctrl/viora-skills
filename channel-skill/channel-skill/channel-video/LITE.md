# Видео за одну команду (тир для слабых моделей)

Ты читаешь этот файл и больше ничего про видео читать не надо.

## Одна команда на всё

```bash
python3 tools/watch.py "https://youtu.be/ID"
```

Скрипт берёт субтитры и печатает выжимку до 1500 знаков с таймкодами.
Кадры НЕ скачиваются. Картинка стоит в десятки раз больше контекста, тебе она не нужна.

## Надо конкретное место в видео

```bash
python3 tools/watch.py "URL" --find "цена,лимит,установка"
```

Печатает только строки с этими словами и таймкоды вокруг них.

## Три правила

1. ОДИН ЗАПУСК НА ОДНО ВИДЕО. Повторные запуски дадут тот же текст.
2. ТАЙМКОД В ПОСТ СТАВИМ ТОЛЬКО ЕСЛИ ОН ЕСТЬ В ВЫВОДЕ. Не выдумываем минуты.
3. НЕТ СУБТИТРОВ ЗНАЧИТ НЕТ ПЕРЕСКАЗА. Скажи автору одной строкой и пиши пост
   без ссылок на содержание видео.

## Если скрипт ответил ошибкой

Он печатает одну строку с указанием, что делать. Выполни его и больше не пытайся.
Самая частая причина: нет `yt-dlp`. Тогда попроси у автора текст или ссылку на статью.
