# Ресерч для постов

Слабая модель: читай `channel-research/LITE.md` и всё. Этот файл для средней и сильной.

## Зачем ресерч именно в этом скилле

Пост без цифр это слоп. Цифры берутся только из двух мест: сырьё автора и ресерч.
Пять вещей, которые надо добирать почти всегда:

1. Точное название сервиса латиницей и адрес сайта.
2. Фактический лимит бесплатного тарифа цифрой.
3. Цена платного тарифа, чтобы было с чем сравнить ноль.
4. Срок: когда акция закрывается или когда вышел релиз.
5. Подводный камень: нужна ли карта, нужен ли VPN, есть ли баны по региону.

Если все пять есть в сырье автора, ресерч запускать не надо.

## Команды

| Задача | Команда |
|---|---|
| Общий поиск факта | `python3 tools/research.py "вопрос"` |
| Прочитать страницу | `python3 tools/research.py --read "URL"` |
| Глубокий режим, больше источников | `python3 tools/research.py "вопрос" --deep` |
| Только GitHub | `python3 tools/research.py "вопрос" --source github` |
| Только обсуждения | `python3 tools/research.py "вопрос" --source hn,reddit` |
| Свежее за семь дней | `python3 tools/research.py "вопрос" --days 7` |
| Шире бюджет вывода | `python3 tools/research.py "вопрос" --budget 4000` |
| Машинный вывод | `python3 tools/research.py "вопрос" --json` |
| Проверить окружение | `python3 tools/research.py --doctor` |

Бюджет по умолчанию 1800 знаков. Это осознанный выбор: вывод обязан влезать
в контекст самой слабой модели вместе с QUICKCARD.

## Как ставить вопрос

Плохой вопрос даёт мусор. Формула: НАЗВАНИЕ плюс ЧТО ИМЕННО НАДО плюс ГОД.

| Плохо | Хорошо |
|---|---|
| бесплатные сервисы | Cursor free tier limit requests 2026 |
| про Screenpipe | Screenpipe storage size disk usage гб |
| что нового в ИИ | open weights model release august 2026 |

Вопрос можно писать по-русски, но название и термины всегда латиницей.
Скрипт сам делает второй прогон на английском, если русский дал мало.

## Маршруты по типу задачи

| Зачем | Флаг | Где ищет |
|---|---|---|
| Цена, лимиты, тарифы | без флагов | веб-поиск плюс страница тарифов |
| Жива ли репа, сколько звёзд | `--source github` | GitHub |
| Реальные отзывы людей | `--source hn,reddit` | Hacker News, Reddit |
| Свежая новость | `--days 7` | веб-поиск с фильтром даты |
| Конкретная страница | `--read URL` | чтение в текст |
| Видео | `tools/watch.py` | субтитры YouTube |

Подробно про источники и их грабли: `channel-research/SKILL.md`.

## Как читать вывод

Скрипт печатает блоки вида:

```
[1] Заголовок источника
    src: web | url: https://...
    Сжатая выжимка без воды.
```

Внизу идёт строка `FACTS:` со всеми найденными числами, ценами и датами.
Переноси в пост только то, что есть в `FACTS:`, и только если рядом есть адрес источника.

Если два источника спорят о цифре, берём тот, где дата свежее. Если даты нет,
пишем осторожнее: «около X» или «у меня вышло X».

## Гигиена контекста

Главная ошибка сильных моделей: они тянут всю страницу в контекст и теряют голос бренда.
Четыре правила:

1. Не больше 3 запусков `research.py` на один пост, не больше 1 запуска `watch.py`.
2. `--read` только для страниц тарифов и документации. Для новостей достаточно выжимки.
3. Не копируй вывод скрипта в пост. Из каждого источника берёшь одну цифру или один факт.
4. После ресерча вернись к голосу бренда. Найденный текст всегда сухой и официальный,
   перепиши его своими словами. Линтер поймает скопированный канцелярит на стоп-словах.

## Когда ресерч НЕ нужен

1. Автор сам принёс ссылки и цифры.
2. Пост личный или девлог про свой проект.
3. Пост короткий шортс или опрос.
4. Надо только почистить готовый текст.

Лишний ресерч стоит времени и контекста, а пользы не даёт.

## Границы

Не лазим за платные стены, не обходим защиту от ботов, не собираем личные данные людей.
Ссылка на пиратскую копию в пост не идёт никогда, даже если ресерч её нашёл.

## Источники и их грабли

Что `tools/research.py` умеет и в каком порядке пробует. Порядок важен: первым идёт то,
что работает без ключей.

### Цепочка веб-поиска

| Шаг | Что делает | Нужен ли ключ |
|---|---|---|
| 1 | DuckDuckGo без оболочки (lite) | нет |
| 2 | чтение страницы через прокси-читалку r.jina.ai | нет |
| 3 | прямое скачивание страницы и вырезание тегов | нет |
| 4 | Exa через mcporter, если оказался в системе | да, если настроен |

Грабли. DuckDuckGo иногда отдаёт капчу вместо выдачи. Скрипт видит это и переходит
на следующий шаг сам. Не повторяй запрос руками.

### GitHub

Искать репы и смотреть, жив ли проект. Для рубрик #сервисы и #релиз это главный источник.

Что смотрим всегда:

1. Звёзды. Меньше 300 значит в пост идёт только с оговоркой «сыровато».
2. Дата последнего коммита. Старше года значит проект мёртвый, в пост не берём.
3. Лицензия. Нет лицензии значит не советуем тащить в коммерческий проект.
4. Открытые ошибки про установку. Готовый подводный камень для блока ВАЖНО!.

### Hacker News и Reddit

Сюда идём за честностью. В обсуждениях лежат те самые подводные камни,
которые не напишут на сайте сервиса.

Одна строка из обсуждения часто становится лучшим блоком ВАЖНО! в посте.
Но цитату не копируем дословно и не приписываем себе чужой опыт.
Формулируем так: «люди жалуются, что ...».

Reddit требует нормальный User-Agent, иначе отвечает отказом. Скрипт его ставит сам.

### YouTube

Видео смотрим только через `tools/watch.py`. Он берёт субтитры, а не картинку,
потому что картинка стоит в десятки раз больше контекста. Подробно: `channel-video/SKILL.md`.

### Ленты RSS

Для новостей и релизов ленты точнее поиска: там есть точная дата.
Скрипт умеет читать любой RSS или Atom по `--read`.
Готовый приём для релизов репозитория: адрес вида `.../releases.atom`.

### Чего в скрипте НЕТ осознанно

В исходном скилле были каналы для соцсетей и бирж, которые требуют логина,
вытаскивания куки из браузера или платных ключей. Они не перенесены:

1. Слабая модель всё равно не настроит ключи и зависнет на ошибках авторизации.
2. Для постов тех-канала ценны только веб, GitHub, HN и Reddit.
3. Каждый лишний канал это ещё сотни знаков инструкций в контексте.

Нужен такой источник разово: попроси автора кинуть адрес и прочитай его через `--read`.

### Проверка окружения

```bash
python3 tools/research.py --doctor
```

Печатает три строки: есть ли сеть, работает ли поиск, есть ли yt-dlp для видео.
Гонять перед каждым постом не надо. Только когда что-то упало два раза подряд.
