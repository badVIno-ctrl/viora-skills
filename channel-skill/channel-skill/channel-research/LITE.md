# Ресерч за одну команду (тир для слабых моделей)

Ты читаешь этот файл и больше ничего про ресерч читать не надо.

## Надо узнать факт

```bash
python3 tools/research.py "твой вопрос словами"
```

Скрипт сам выбирает, куда идти: веб-поиск, GitHub, Hacker News, Reddit, ленты.
Вывод сжат до 1800 знаков, чтобы не забить контекст.

## Надо прочитать конкретную страницу

```bash
python3 tools/research.py --read "https://адрес"
```

## Надо понять видео

```bash
python3 tools/watch.py "https://youtu.be/ID"
```

## Три правила, которые надо соблюдать

1. ОДИН ЗАПУСК НА ОДИН ФАКТ. Не гоняй скрипт по пять раз подряд с похожими словами.
   Максимум 3 запуска на один пост.
2. ЦИФРА ИЛИ СРОК ИЛИ ЦЕНА. Если вывод не дал ни одного числа, ресерч провален.
   Пиши в посте только то, что подтверждено.
3. НЕТ ФАКТА ЗНАЧИТ НЕТ СТРОКИ. Никогда не выдумывай лимиты, цены и даты.
   Лучше написать автору одной строкой «не нашёл цену, проверь».

## Если скрипт ответил ошибкой

Он печатает одну строку с указанием, что делать. Выполни его и больше не пытайся.
Если сети нет вообще: скажи автору одной строкой и пиши пост только по его сырью.
Выдуманные факты хуже, чем отсутствие фактов.
