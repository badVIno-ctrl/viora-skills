# Источники и их грабли

Что `tools/research.py` умеет и в каком порядке пробует. Порядок важен: первым идёт то,
что работает без ключей.

## Цепочка веб-поиска

| Шаг | Что делает | Нужен ли ключ |
|---|---|---|
| 1 | DuckDuckGo без оболочки (lite) | нет |
| 2 | чтение страницы через прокси-читалку r.jina.ai | нет |
| 3 | прямое скачивание страницы и вырезание тегов | нет |
| 4 | Exa через mcporter, если оказался в системе | да, если настроен |

Грабли. DuckDuckGo иногда отдаёт капчу вместо выдачи. Скрипт видит это и переходит
на следующий шаг сам. Не повторяй запрос руками.

## GitHub

Искать репы и смотреть, жив ли проект. Для рубрик #сервисы и #релиз это главный источник.

Что смотрим всегда:

1. Звёзды. Меньше 300 значит в пост идёт только с оговоркой «сыровато».
2. Дата последнего коммита. Старше года значит проект мёртвый, в пост не берём.
3. Лицензия. Нет лицензии значит не советуем тащить в коммерческий проект.
4. Открытые ошибки про установку. Готовый подводный камень для блока ВАЖНО!.

## Hacker News и Reddit

Сюда идём за честностью. В обсуждениях лежат те самые подводные камни,
которые не напишут на сайте сервиса.

Одна строка из обсуждения часто становится лучшим блоком ВАЖНО! в посте.
Но цитату не копируем дословно и не приписываем себе чужой опыт.
Формулируем так: «люди жалуются, что ...».

Reddit требует нормальный User-Agent, иначе отвечает отказом. Скрипт его ставит сам.

## YouTube

Видео смотрим только через `tools/watch.py`. Он берёт субтитры, а не картинку,
потому что картинка стоит в десятки раз больше контекста. Подробно: `channel-video/SKILL.md`.

## Ленты RSS

Для новостей и релизов ленты точнее поиска: там есть точная дата.
Скрипт умеет читать любой RSS или Atom по `--read`.
Готовый приём для релизов репозитория: адрес вида `.../releases.atom`.

## Чего в скрипте НЕТ осознанно

В исходном скилле были каналы для соцсетей и бирж, которые требуют логина,
вытаскивания куки из браузера или платных ключей. Они не перенесены:

1. Слабая модель всё равно не настроит ключи и зависнет на ошибках авторизации.
2. Для постов тех-канала ценны только веб, GitHub, HN и Reddit.
3. Каждый лишний канал это ещё сотни знаков инструкций в контексте.

Нужен такой источник разово: попроси автора кинуть адрес и прочитай его через `--read`.

## Проверка окружения

```bash
python3 tools/research.py --doctor
```

Печатает три строки: есть ли сеть, работает ли поиск, есть ли yt-dlp для видео.
Гонять перед каждым постом не надо. Только когда что-то упало два раза подряд.
