# CHANNEL SKILL

@AGENTS.md

Короткая версия, если некогда открывать AGENTS.md:

1. Длинных тире нет нигде: ни в посте, ни в статье, ни в этом чате. Только `-`.
2. Шаг ноль: кто автор и какой канал, берётся только из профиля. Профиля нет,
   значит сначала интервью, из каталога `channel-skill`:
   `python3 tools/onboard.py`. Проверить: `python3 tools/profile.py --check`.
3. Слабая модель или маленькое окно: читай `channel-skill/QUICKCARD.txt` и всё.
4. Обычная работа: читай `channel-skill/SKILL.md`.
5. Перед выдачей поста, из каталога `channel-skill`:
   `python3 tools/channel.py ship draft.txt --rubric гайд`. Код 0 значит готово.
   Свой список рубрик: `python3 tools/profile.py --show`.
6. Пост длиннее 1800 знаков или больше семи пунктов: `channel-skill/reference/split.md`.
7. Имя автора, канал, тон, ссылки и цифры берём из профиля, а не из примеров
   и не из головы. Демо-данные годятся только для тестов.
8. Публикует автор. Скилл отдаёт черновик и ждёт слова.
