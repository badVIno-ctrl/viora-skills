# CHANNEL SKILL 6.1.0 - точка входа для агента

Это рабочая папка скилла, который пишет посты, статьи и сценарии для
телеграм-канала голосом его автора, а также ресерчит интернет и смотрит видео.

**Кто автор, как называется канал, какой у него голос и какие рубрики: всё это лежит
в профиле, а не в файлах скилла.** Скилл один, авторы разные.

Язык работы берётся из профиля, по умолчанию русский.

## ПРАВИЛО НОЛЬ. Читай раньше всего остального

**Длинных тире не бывает. Ни в постах, ни в статьях, ни в твоих ответах в чате.**

Запрещённые символы: em dash (U+2014), en dash (U+2013), horizontal bar (U+2015),
figure dash (U+2012), minus sign (U+2212).

Вместо них: обычный дефис `-`, точка, запятая, двоеточие или новое предложение.
Правило действует всегда: в посте, в статье, в коммите, в комментарии к коду
и в обычном разговоре с автором. Длинное тире это самая заметная подпись ИИ
в русском тексте, и автор её видит первой.

Проверить свой собственный ответ перед отправкой:

```bash
cd channel-skill
echo "текст ответа" | python3 tools/lint_chat.py
```

## Шаг ноль. Чей это канал

Профиль автора это единственный источник правды про бренд: имя, тон, аудитория,
темы, табу, ссылки, футер, рубрики, цифры канала и окно публикации.

| Ситуация | Что делаешь |
|---|---|
| Профиля нет, автор только поставил скилл | не пишешь текст, а проводишь интервью: `python3 tools/onboard.py` |
| Автор отвечает в чате, а не в консоли | берёшь вопросы `python3 tools/onboard.py --questions`, потом кладёшь ответы через `--stdin` |
| Не уверена, чей это канал | `python3 tools/profile.py --who` и `python3 tools/profile.py --check` |
| Автор поменял темы, ссылки или рубрики | `python3 tools/onboard.py --force`, потом `--render` |
| Надо понять поля профиля | `channel-skill/profile/README.md` и `channel-skill/profile/profile.example.json` |
| Автор хочет связать Телеграм | `docs/TELEGRAM.md` |

Длинное описание интервью и того, что скилл делает с ответами: `channel-skill/ONBOARDING.md`.

Два запрета на этом шаге: не выдумывать бренд за автора и не брать демо-данные
из примера за чистую монету. Демо-профиль нужен только для тестов и примеров.

## Шаг 1. Выбери свой тир и не читай лишнего

Скилл собран так, чтобы не забивать контекстное окно. Читаешь ровно один файл
из таблицы, дальше по ссылкам внутри него.

| Кто ты | Что читаешь |
|---|---|
| Слабая или быстрая модель, маленькое окно, режим автодополнения | `channel-skill/QUICKCARD.txt` |
| Обычная модель, есть доступ к файлам | `channel-skill/SKILL.md` |
| Сложная задача, нужны детали | `channel-skill/SKILL.md`, дальше по `channel-skill/ROUTER.md` |
| Среда без файловой системы, только чат | вставить `channel-skill/PROMPT-CORE.txt` |

Точные размеры всех файлов считаются скриптом и лежат в `channel-skill/ROUTER.md`.

Признак того, что тебе хватит QUICKCARD: ты не уверена, что удержишь двадцать
правил одновременно. Тогда не держи их. Держи семь и гоняй линтер, он знает всё
остальное и говорит, что именно править.

## Шаг 2. Что вообще просят

| Задача автора | Куда идти |
|---|---|
| Написать пост в канал | `channel-skill/SKILL.md`, пайплайн из восьми шагов |
| Не понятно, в каком порядке идут блоки текста | `channel-skill/reference/frameworks.md` |
| Посты похожи один на другой, всегда список | `channel-skill/reference/matrix.md` |
| Пост правильный, но его никто не пересылает | `channel-skill/reference/mirror.md` |
| Пост получился длинный, больше семи пунктов | `channel-skill/reference/split.md` |
| Собрать статью на telegra.ph | `channel-skill/reference/telegraph.md` |
| Найти инфу в интернете, проверить сервис, посмотреть чужие посты | `channel-skill/channel-research/SKILL.md` |
| Посмотреть видео, разобрать чужой ролик | `channel-skill/channel-video/SKILL.md` |
| Сделать пост красивее, разобрать вёрстку | `channel-skill/reference/beauty.md` |
| Убрать ИИ-слова, вычистить текст | `channel-skill/reference/antislop.md` |
| Настроить канал, ключи, описание | `channel-skill/reference/seo.md` |
| Собрать шортс | `channel-skill/reference/shorts.md` |

## Шаг 3. Команды

Все команды запускаются из каталога скилла: сначала `cd channel-skill`,
дальше ровно так, как написано ниже. Так же написаны команды во всех
файлах скилла, чтобы их можно было копировать без правки. Если забыла сделать
cd, точка входа сама напомнит одной строкой и всё равно сработает.
Питон только стандартный, ставить ничего не нужно.

Имена рубрик в примерах взяты из набора по умолчанию. Свой список рубрик
автор видит командой `python3 tools/profile.py --show`.

```bash
# шаг ноль: интервью про автора и канал
python3 tools/onboard.py

# проверить профиль и посмотреть, чей это канал
python3 tools/profile.py --check
python3 tools/profile.py --who

# главная команда номер один: план по задаче
python3 tools/channel.py route "нужен пост про новый инструмент"

# главная команда номер два: автоправка, линтер, оценка и разрез сразу
python3 tools/channel.py ship draft.txt --rubric гайд

# шесть вариантов первой строки под тему и рубрику
python3 tools/channel.py hook "тема поста" --rubric гайд

# починить только механику вёрстки и перезаписать файл
python3 tools/lint_post.py draft.txt --fix --rubric гайд

# поставить посту оценку на цифрах канала из профиля
python3 tools/score_post.py draft.txt

# память канала и проверка приветствия на повтор
python3 tools/memory.py show
python3 tools/memory.py check-greeting "первая строка поста"

# проверить черновик поста, строго и машинно
python3 tools/lint_post.py draft.txt --strict
python3 tools/lint_post.py draft.txt --json

# нужно ли резать пост на пост плюс статью
python3 tools/split_post.py draft.txt --check
python3 tools/split_post.py draft.txt --out /tmp/post

# проверить свой ответ в чате на ИИ-слова и длинные тире
python3 tools/lint_chat.py --text "твой ответ"

# ресерч по интернету и просмотр видео
python3 tools/research.py "что искать"
python3 tools/watch.py "https://youtu.be/ID"

# мост с Телеграмом: свои ключи, свой канал
python3 tools/tg.py setup
python3 tools/tg.py doctor

# поставить скилл в свой проект: копия в .claude, .agents и .cursor
python3 tools/install.py --target /путь/до/проекта --dry-run

# проверить упаковку скилла по спеке Agent Skills
python3 tools/validate_skill.py

# прогнать эталоны поведения
python3 tools/run_evals.py

# проверить среду: питон, файлы, память, сеть, yt-dlp
python3 tools/channel.py doctor

# собрать поставку в dist
python3 tools/package.py --check

# полный прогон перед тем, как считать скилл рабочим
bash tools/check_all.sh
```

## Шаг 4. Что нельзя никогда

1. Писать текст без профиля автора. Нет профиля, значит сначала интервью.
2. Подставлять демо-имена, демо-ссылки и демо-цифры в живой пост.
3. Выдумывать ссылки, домены, цифры, сроки и опыт автора. Нет в сырье, спрашиваем одной строкой.
4. Ставить длинные тире. Смотри правило ноль.
5. Отдавать пост без футера и без хэштега-рубрики, когда они включены в профиле.
6. Писать в первой строке приветствие длиннее, чем разрешает профиль.
7. Заканчивать пост риторическим вопросом. Заканчиваем просьбой переслать.
8. Отдавать пост, который не прошёл `channel-skill/tools/lint_post.py` в режиме --strict.
9. Публиковать самому. Скилл отдаёт текст автору, публикует автор.

## Структура папки

```
<корень репозитория>/
  AGENTS.md                    этот файл, точка входа
  CLAUDE.md GEMINI.md          то же для Claude Code и Gemini
  .cursorrules .cursor/rules/  то же для Cursor
  README.md                    человеческое описание и быстрый старт
  docs/                        инструкции для человека, включая Телеграм
  secrets/                     шаблоны ключей, сами ключи в гит не едут
  hooks/                       подсказка на старте сессии
  start-watch.sh .ps1          смена в Телеграме одним запуском
  channel-skill/
    ONBOARDING.md              интервью про автора и канал
    profile/                   профиль автора, пример и шаблоны
    QUICKCARD.txt              тир 0: одна карточка на всё
    SKILL.md                   тир 1: пайплайн и правила
    ROUTER.md                  что читать под какую задачу
    PROMPT-CORE.txt            ядро для среды без файлов
    PROMPT-FULL.txt            всё одним файлом
    reference/                 тир 2: детали по одной теме на файл
    channel-research/            интернет-ресерч
    channel-video/               просмотр видео
    memory/                    цифры, решения, что уже выходило
    posts/                     архив вышедших постов и индекс
    evals/                     эталоны поведения и фикстуры
    tools/                     интервью, линтеры, резчик, ресерч, видео, сборка
```
