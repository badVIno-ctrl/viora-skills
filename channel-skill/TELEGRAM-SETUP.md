# Телеграм за два шага

Подробная инструкция живёт в одном месте: `docs/TELEGRAM.md`.
Этот файл оставлен как короткая памятка на один экран.

## Главное в двух строках

Ключи телеграма у каждого свои: в поставке их нет и быть не может.
Скилл работает и без телеграма: тогда черновики просто приходят в чат.

## Шаг 1. Свои ключи

1. Открой my.telegram.org, раздел API development tools.
2. Создай приложение и забери `api_id` и `api_hash`.
3. Скопируй шаблон и впиши их туда:

```bash
cp secrets/telegram.env.example secrets/telegram.env
```

Файлы из `secrets/` в гит не уезжают: это уже прописано в `.gitignore`.

## Шаг 2. Вход и проверка

```bash
python3 channel-skill/tools/tg.py setup
python3 channel-skill/tools/tg.py doctor
```

Спросит номер вида `+79001234567`, потом код из Телеграма, потом пароль облака,
если включена двухфакторка. Один раз.

## Как этим пользоваться

Пишешь себе в Избранное строку с префиксом из профиля, например `/post гайд про свет`.
Скилл забирает заявку, приносит черновик и ждёт слова автора. Без этого слова
в канал не уходит ничего.

Сторож, который смотрит Избранное сам:

```bash
bash start-watch.sh
```

Виндовс: `powershell -ExecutionPolicy Bypass -File .\start-watch.ps1`

## Если что-то не так

Разбор ошибок, режимы публикации и безопасность сессии: `docs/TELEGRAM.md`.
