## Для обычного человека
Агент сначала знакомится с вами и каналом, запоминает ответы и сам выбирает настройки.
Готовая выдача: ролик, обложки, субтитры и один ПАКЕТ.txt со всем для публикации.
Не нужно читать JSON, запускать команды или исправлять код. Если ролик не набирает,
пришлите его и скриншоты цифр: агент предложит одну проверяемую правку.
Длинное видео имеет локальный горизонтальный экспорт schema 1.4 через render/qa/all.
Профиль возможностей и ограничения: reference/long-videos.md. Тейки, жанровые проверки
и накопление ниши: ROUTER.md. Отчёт приёмки и непроверенное: acceptance/REPORT.md.

## Установка за три шага
1. Положи папку `shorts-2.0/` в папку скиллов агента (`.claude/skills/`, `.agents/skills/` или рядом с проектом).
2. Нужны Python 3.11+ и ffmpeg с libass. Запусти `bash tools/install.sh` (создаст `.venv`, поставит зависимости,
   Chromium при необходимости, и покажет `doctor`).
3. Проверь: `bash tools/check_all.sh` (с `PYTHON=.venv/bin/python`, если venv). Зелёные автотесты — только техническая проверка, не публикационная приёмка. Нужны просмотр, слух и release-check.

Дальше просто попроси агента: "сделай шортс про эти два сайта ...", "эдит из фильма ... под трек ...",
"нарежь моё видео на 3 шортса". Агент читает `SKILL.md`.

## Переменные окружения (все необязательные)

|---|---|

| `SHORTS_MEMORY` | где хранить `prefs.json`, историю (по умолчанию `memory/`) |

| `SHORTS_TTS` | принудительный TTS: `edge`, `elevenlabs`, `openai`, `piper`, `silent` |

## Согласование платных API (v3.4)
Потенциально платные HTTP-запросы TTS OpenAI/ElevenLabs и генерации обложек OpenAI/Gemini
по умолчанию заблокированы, даже при наличии API-ключей. Получить разрешение на конкретный
объём/бюджет, затем установить SHORTS_ALLOW_PAID=1 только для этого задания и сбросить после.
Флаг не является счётчиком расходов и не разрешает публикацию/закупку трафика.
Кэш озвучки и локальная сборка обложек из кадров не требуют платного запроса.
Если API заблокирован, не объявлять генерацию успешной: использовать разрешённый fallback
или сообщить точный блокер. Согласование и лимиты записать в бриф/отчёт.

Быстрая автономная проверка рекламного расширения: `bash tools/check_ads.sh`
(или `PYTHON=/path/to/python bash tools/check_ads.sh`). Она проверяет контракты и защиту,
не запускает рекламу и не заменяет редакторскую оценку креативов.
Перед заменой папки скилла сохранить свою локальную memory/ и пользовательские исходники;
примеры из архива не являются вашим профилем. Работа следующего агента начинается с SKILL.md.
