# QA и блокеры
Финальный файл и SHA-256:
- [ ] Подтверждённый продукт / аудитория / действие / допуск источника
- [ ] Реестр утверждений: нет выдуманных скидок, отзывов и дохода
- [ ] Права на все исходники / музыку / логотип
- [ ] Смысл и текст в телефонном размере
- [ ] Весь интервал: лицо/товар/интерфейс/субтитры/UI не перекрыты
- [ ] Понятно без звука; субтитры/тайминг/переносы проверены
- [ ] Полный финальный MP4 просмотрен в движении и прослушан (для PNG - проверен PNG)
- [ ] CTA и реальная кликабельная точка перехода
- [ ] Посадочная / ГЕО / язык / цена / параметры / финальный QR
- [ ] Применимые правила рекламы / партнёрства и раскрытие
- [ ] Метрика / атрибуция / расходы / остановка
- [ ] Конкретное согласование публикации и, отдельно, расходов
Для каждого: что сделано / доказательство / дата / применимость / статус.
Блокеры и статус выдачи: черновик / превью / согласовано к конкретному запуску.

В campaign.qa у static_ad только motion_audio/subtitles могут иметь
applicability="not_applicable", passed=false, evidence с причиной.
Остальные пункты и видео: applicability="applicable" (или поле отсутствует).
Сохранять ad-qa-draft.json / ad-qa-launch.json; ad-qa.json содержит последний результат.

## Добавлено в v3.5 (обязательно для launch)

- [ ] Доказательства оффера, прав и правил не старше evidence_max_age_days (по умолчанию 30)
- [ ] Раскрытие рекламы/партнёрства: текст, видимость в креативе, место, платформенная метка

      только профиль, brand deal, Posts (проверить в интерфейсе площадки сейчас)
