# Источники из интернета: `fetch` и лестница доступа

Главное: **ты достаёшь видео и музыку сам**. Не проси пользователя скачать файлы, пока `fetch` не вернул `FAIL`.
Проверено 2026-10-21: обычный `yt-dlp` с JS-рантаймом скачал Shorts, куски интервью, стендапа, геймплея и аудио из плейлиста.

## Команда
```
python tools/shorts.py fetch --probe URL1 URL2            # название, автор, длительность: тот ли ролик
python tools/shorts.py fetch URL --section 7.0-16.0 --out sources --name interview_a
python tools/shorts.py fetch URL --audio --section 0:30-0:50 --out sources --name music3
python tools/shorts.py fetch --list items.json --out sources   # [{"url","name","section","audio"}]
```
Скачивается только нужный кусок (`--download-sections`), для фильма и интервью на 2 часа это секунды. Берут с запасом
1-2 с с каждой стороны и режут точно уже в `stack`.

## Лестница (сверху вниз, каждая попытка в `fetch-status.json`)
1. Свежий yt-dlp + JS-рантайм: `node` подключается флагом `--js-runtimes node`, deno работает по умолчанию, пакеты
   `yt-dlp[default]` (yt-dlp wiki, страница EJS). Без рантайма часть форматов YouTube пропадает.
2. Другие клиенты плеера: default, web_safari, mweb, tv, android_vr, ios.
3. Cookies самого пользователя: `SHORTS_YTDLP_COOKIES=/путь/cookies.txt` или `SHORTS_YTDLP_BROWSER=chrome|firefox`.
   Просить их только если шаги 1, 2 и 5 не помогли, лучше запасной аккаунт.
4. Прокси пользователя: `SHORTS_YTDLP_PROXY=...`. Бесплатные списки прокси не использовать.
5. Обновление yt-dlp (`pip install -U yt-dlp[default]`) и повтор лестницы.
6. Общий браузер (`SHORTS_BROWSER_CDP`): кусок пишется при воспроизведении, время записи равно длине куска. Только для кусков.
Классы ошибок: `bot_block`, `unavailable`, `geo`, `age`, `outdated_or_formats`, `rate_limit`, `other`. Для `unavailable`, `geo`,
`age` без cookies пользователя лестница не крутится вхолостую.

## Если всё провалилось
`fetch` печатает `FAIL`, что пробовал и ОДНУ готовую команду для компьютера пользователя (домашний IP, скачивается только
нужный кусок). Одно сообщение, коротко: какие именно файлы и как назвать. Все остальные ролики и независимые части
доделываются дальше. Объяснять пользователю «правила скилла запрещают» нельзя: такого правила нет.

## Что не делать
DRM, платные и закрытые видео, чужие аккаунты, пароли в чате, подмена исходника похожим роликом или другой музыкой.

## Расхождение подписи и ссылки
Подпись ссылки (текст) и адрес (href) в задании могут не совпадать. `fetch --probe` для обоих и выбор того, что совпадает
с описанием задания (например «машинка», «интервью Гайдуляна»). Сказать выбранное одной строкой, не спрашивать.

## Логотипы
Официальный аватар публичного бота или канала: `"tg": "handle"` в карточке баннера (берётся og:image страницы t.me/handle).
Если страницы нет, рисуется честная монограмма без выдуманного знака.
