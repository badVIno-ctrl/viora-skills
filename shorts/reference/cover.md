# Обложка

Основа: исследование (2.1, 2.2, 7), правила дизайна автора, образец `viora-v8/refs/ref-4-thumbnails-style.png`.
- Шортс в ленте стартует с ПЕРВОГО КАДРА: он и есть обложка. Поэтому первый кадр = готовый результат + метка 2-4 слова.
- Отдельная обложка нужна для канала, поиска, шеринга: `cover DIR`.
- **Текст всегда рисует код** шрифтом бренда. Картинка: модель, пользователь (`--image`) или кадр ролика.
  Для фильмов и видео кадр берётся из исходника в его разрешении (резче, чем вертикальный рендер).

## 3 варианта, у каждого своя идея (1280x720 и 1080x1920, плюс превью 150 px и 320 px)
- **A minimal**: чёрный фон, один предмет-символ линией (замок, ключ, окно браузера, шахматный король, шестерёнка,
  кнопка play, `</>`, график, чип), крупный белый капс, много воздуха. Единственный акцент: маленькая деталь символа
  (скважина замка, бородка ключа, точка окна). Символ выбирается по словам темы (`metadata.topic`, текст обложки,
  имя ролика); свой символ: `metadata.cover_symbol` в плане.
- **B hero**: один герой-объект крупно (картинка модели без текста, если есть ключ, иначе лучший кадр с наездом на
  центр масс) + ОДИН акцент: плашка цвета бренда под текстом.
- **C split**: два момента рядом (до / после), одна акцентная линия-разделитель, текст на плоской чёрной полосе.
  Если кадр всего один: `outline` (затемнённый кадр + крупный текст с обводкой).

## Тон: громкая, средняя, спокойная (2.0)
Три обложки соответствуют трём тонам названий и описаний. У каждой СВОЙ текст (3-5 слов, не копия соседней) и своя подача:
- **громкая = B hero** (`loud`): крупный объект, капс-крючок («ИИ СДЕЛАЛ 8 ПУШЕК»), самый сильный контраст, один честный
  шокирующий акцент;
- **средняя = C split** (`medium`): до / после, понятный вопрос или обещание («КАК ЗАЩИТИТЬ ПАРОЛЬ»);
- **спокойная = A minimal** (`calm`): символ темы линией, много воздуха, информативная фраза («Защита паролей: коротко»).
Тексты берутся из `metadata.json` -> `cover_texts` [{tone, text}] (их пишет агент в `metadata.draft.json`, ровно 3, до 5 слов).
Нет `cover_texts`: код строит три разных текста из хука и темы (громкий всегда капсом). `cover --text "..."` задаёт один текст
сразу для всех трёх. В `cover/cover.json`: `tones` (буква -> тон), `texts` (буква -> текст), у каждого варианта поля `tone` и `text`.
Буквы A/B/C и файлы `cover-A-...` остаются прежними, поэтому порядок «от громкого к спокойному» это B, C, A.

## Проверки (код)
3-5 слов; основная проверка глазами на 150 px, дополнительная на 320 px (высота букв от 14 px); контраст текста от 4.5:1 по кольцу вокруг реальных букв;
"прищур" (серый, 320 px, размытие: фигура и текст остаются отдельной формой, тон от 3:1); нет свечения (кольцо 3-12 px
вокруг букв не светлее фона); нет градиента на том, что нарисовал код (плашки, полосы, фон); 16:9 без текста в правом
нижнем углу (время); 9:16 внутри safe-зоны; три варианта не похожи друг на друга (dhash). Замечания пишутся в
`cover/cover.json` и в `all` выводятся как WARN (код выхода `all` = итог QA).

## Генератор картинок
`OPENAI_API_KEY` (gpt-image-1) или `GEMINI_API_KEY` (gemini-2.5-flash-image), `SHORTS_IMAGE_PROVIDER` для выбора или `none`.
Модель рисует только картинку героя БЕЗ ТЕКСТА, текст накладывает код. Вызов API не проверен без ключа (тест
подменяет вызов): при ошибке движок честно откатывается на кадры.
Нет генератора: `cover/prompt.md` содержит отдельный промпт на каждый вариант с тоном и текстом обложки
(`## A minimal (calm)`, `## B hero (loud)`, `## C split (medium)`); перенеси простые промпты A/B/C в итоговый ПАКЕТ.txt. Предложи прислать картинку, но не заставляй разбирать папки.
Нельзя: неон, свечение, фиолетово-синие градиенты, кинематографичные клише, коллаж, чужой бренд или лицо.

## Мобильный просмотр и правило «не трогай»
Код сохраняет превью 150 px и считает высоту букв (предупреждение при менее 7 px),
но это лишь прокси. Агент обязательно открывает превью: за полсекунды различимы главный
объект и текст? Нет - укрупнить, сократить слова и проверить снова. 320 px - дополнительный тест.
Тезис «70%+ просмотров - мобильные» из сторонней сводки - ориентир, проверяется на ваших цифрах.
Если CTR нового видео выше среднего канала - обложку НЕ менять. Если заметно ниже за 24-48 ч,
сравни сопоставимые источники показов и только потом пробуй новую упаковку. В ленте Shorts
первый кадр - это и есть обложка; не выдавай CTR обложки за метрику пролистывания.
Правило и внешние цифры - рабочая гипотеза longwave, не требование алгоритма.
Источник: исследование автора, файлы 06, 24, 25 в research/traffic-v3.1.

## Согласование платных API (v3.4)
Потенциально платные HTTP-запросы TTS OpenAI/ElevenLabs и генерации обложек OpenAI/Gemini
по умолчанию заблокированы, даже при наличии API-ключей. Получить разрешение на конкретный
объём/бюджет, затем установить SHORTS_ALLOW_PAID=1 только для этого задания и сбросить после.
Флаг не является счётчиком расходов и не разрешает публикацию/закупку трафика.
Кэш озвучки и локальная сборка обложек из кадров не требуют платного запроса.
Если API заблокирован, не объявлять генерацию успешной: использовать разрешённый fallback
или сообщить точный блокер. Согласование и лимиты записать в бриф/отчёт.
