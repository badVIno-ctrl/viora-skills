# Эдиты из фильмов и нарезки

## Эдит из фильма (1.2): реплика -> дроп -> герой на битах
Так делают настоящие эдиты (разбор урока Tifofey "Как сделать ЭДИТ в CapCut с нуля за 9 минут" и раздел 20
исследования `docs/research-log.md`). Структура, которую строит `edit`:

| Время | Что | Зачем |
|---|---|---|
| 0 .. D (2-6 с) | **короткая реплика из фильма**: оригинальный звук, субтитры "вырастают" и уходят в размытие, музыка тихо под голосом (-16 дБ) | хук: смысл и голос героя с первого кадра, кадр 0 = лицо |
| D | **дроп трека ровно в конец реплики** + вспышка (2.2: без синтезированного райзера и удара, дроп делает сам трек) | главный момент, "смена мира" |
| D .. 18 с | шоты героя на сильных долях (~0.85-1.2 с), у каждого кривая скорости "быстро - зависание - быстро" (velocity, 6x -> 0.5x -> 5x, оптический поток), лицо по центру кадра 9:16 | ритм, склейки прячутся в скорости |
| ~25% и ~62% | два длинных "героя" (двойная длина, глубокое зависание 0.3x) | пики эмоции |
| перед вторым героем | двойной быстрый стык (по 1 доле) | смена ритма |
| ~45% и последние 2.6 с | **ссылка выезжает в центр** (плашка, по центру по горизонтали с точностью до пикселя), без звука-свиста | ник/ссылка 2 раза (иссл. 5.2) |

Без панелей сверху и снизу (`center_only`), без плашки с названием фильма, без QR (в Shorts его нечем сканировать).
Петля: конец на сильной доле, ролик сразу стыкуется с началом.

### Команды
```bash
# 1) найти реплику: строки диалога (транскрипт YouTube через общий браузер или faster-whisper для файла)
python3 tools/shorts.py film-lines URL --grep "сила|правд"
# 2) план + запись всех кусков в DIR/media (план самодостаточный)
python3 tools/shorts.py edit --video URL --line "Вот ты говорил город сила А здесь слабые все" \
    --music трек.mp3 --link t.me/NAME -o out/brat/plan.json
python3 tools/shorts.py render out/brat/plan.json --out out/brat && python3 tools/shorts.py qa out/brat
```
Опции: `--music файл|URL` (**обязательно** с 2.2: трендовый или лицензированный трек; `--music builtin` = сгенерированная
заглушка `edit.mp3` только для черновика, `deliver` её не выдаёт), `--line-at 5283.5-5288` (по времени),
`--line-text "текст"` (если распознано криво), `--length 18`, `--look film|cold|punchy|bw|none`,
`--whisper small` (модель для слов реплики), `--classic` (старый эдит 1.1 без реплики).

### Как выбирается реплика
Хорошая реплика: 3-10 слов, говорит главный герой, фраза законченная и узнаваемая ("цитата"), без мата и оскорблений.
Ищи по `film-lines --grep` ключевые слова темы, бери **одну мысль**. Время уточняет faster-whisper по записанному
куску (язык задан, без VAD: VAD режет тихий голос под музыкой). Если слова не совпали, берётся речь по энергии голоса
в этом месте, а текст субтитров = твоя фраза из `--line`.

### Как выбираются шоты
1. Раскадровка YouTube (storyboard, 1 кадр в 10 с на весь фильм, качается без плеера за 2-3 с).
2. Оценка кадра: лицо (YuNet) и его размер (крупный план лучше общего), одно лицо лучше трёх, резкость, контраст, цвет.
   Чёрные кадры и текстовые экраны (титры) выкидываются. Первые 2% и последние 8% фильма пропускаются.
3. **Главный герой**: лица сравниваются (SFace, 37 МБ, качается один раз в `SHORTS_MODELS/faces`), самое частое лицо =
   герой, его кадры x1.3. Нет модели: просто по размеру лица.
4. Разнообразие: между кандидатами от 30 с, одинаковые по цвету сцены в пределах 4 минут не повторяются
   (так больше нет "рынка пять раз"), из каждой восьмой части фильма не больше ceil(n/8)+1.
5. Каждый кандидат записывается (5 с), анализ в полном размере: склейки камеры (шот не пересекает склейку),
   лицо на каждом кадре; начало шота выбирается так, чтобы зависание кривой пришлось на самое крупное лицо.
6. Первый шот после дропа = лучший кандидат, два героя = следующие лучшие, остальные по порядку фильма (история).

### Кадрирование 9:16
`engine/reframe.py`: лицо в центр (YuNet каждые 1/8 с), без лица = центр движения. Стоит на месте, если объект почти
не двигается, иначе плавно ведёт (как Google AutoFlip). Лицо не режется краем.

### Вид (`edit.look`)
`grade` film (тёплый, как "сосна" в CapCut) / cold / punchy / bw / none, резкость краёв, зерно (не на лице),
виньетка, хроматическая аберрация + тряска на ударе в начале шота, лёгкое покачивание. Отдельно `fx.flash` на дропе
и `fx.punch` (зум-удар) на даунбитах.

### Музыка
Лучший звук для эдита = **трендовый трек** из фонотеки платформы (рабочий ориентир: окно тренда 1-3 дня, проверяется на ваших цифрах). Свой трек:
`--music файл|URL` (URL YouTube пишется через браузер, если сервер заблокирован), дроп ищется сам (самый большой
скачок энергии на сильной доле). Своего трека по умолчанию нет (2.2): встроенный `edit.mp3` сгенерирован кодом (808 +
ковбелл = те самые «колокольчики» на дропе в 2.1) и годится только как черновик (`--music builtin`). Нет трека у
пользователя: спроси его или возьми звук из самого фильма; поверх никаких синтезированных райзеров, ударов и свистов.

### QA эдита
`edit_content` (разные шоты, нет титров и чёрного), `beat_sync` (стыки в 50 мс от сильной доли), `edit_style`
(без панелей, плашки CTA по центру +-4 px, кривые скорости у 60%+ шотов, лица по центру у 70%+ шотов с лицом,
дроп = конец реплики +-1.5 кадра, лицо на первом шоте, 7-20 с). Глазами: `contact-*.png`, первый кадр, кадр с дропом.

### Подписи эдита (reference/metadata.md)
Название = цитата или эмоция героя ("Город - злая сила"), 1 строка подписи + 3-5 хэштегов (#эдит #брат #edit ...).
Зашло (досмотры выше обычного): сделай ещё 1-2 эдита с тем же героем в течение 1-3 дней ("доить хит").

## Эдит в бит без реплики (`edit --classic`, 1.1)
Моменты по heatmap/громкости/склейкам, стыки на сильных долях, slow-mo 0.5x на герое. Слабее реплики+дропа,
оставлен для клипов без диалога.

## Нарезка длинного видео (video)
`clips --video файл|URL -n 3 --length 30 --lang ru -o out/clips` -> `clip-1.plan.json`...
Транскрипт faster-whisper (если установлен) или `--transcript words.json`. Каждый план: 3 сцены, звук оригинала,
субтитры из транскрипта, начало с начала фразы. Ты добавляешь `on_screen_text` (хук) на первую сцену и, если нужно,
верхнюю панель и CTA, потом `render` + `qa`.

## Кинорамка и ч/б -> цвет на дропе (1.3)
`edit ... --bars --bw-drop --layer thesis:"..." --layer sound_design:"..."`: реплика в полосах 2.39 и в ч/б,
на дропе полосы раскрываются и цвет растекается от лица, в конце полосы сходятся (петля). Только эти 2 приёма,
поверх обычного эдита (скорость, вспышка на дропе, удары на долях). Авторский слой обязателен (чужой фильм,
исследование 15: эффекты по шаблону слоем не считаются). Подробно: `reference/vfx.md`.

## Доступ к YouTube
yt-dlp, а если сервер заблокирован ("Sign in to confirm you're not a bot"), то запись из общего браузера:
`reference/youtube-access.md`.

## Что решает "залёт"
Удержание: сильный первый кадр, быстрый ритм, петля. Гарантий нет: делаем пачками и смотрим, какой формат даёт
подписчиков (`reference/growth-loop.md`). Для второго канала НЕ тот же файл: другой первый кадр, хук, длина, название.

## Как делают эдит люди: разбор двух туториалов CapCut (2.0)

Источники: «Как сделать ЭДИТ в CapCut с нуля за 9 минут» (Tifofey, https://www.youtube.com/watch?v=wwMeX-qDfoA) и «ТОПОВЫЕ ЭДИТЫ в CapCut» (YoEdit, https://www.youtube.com/watch?v=tjmbz1k9wsU). Проверено: заголовки, описания и тайм-коды первого. Сами видео и их речь из песочницы не открывались (YouTube отдаёт "not a bot"), поэтому второй разобран только по описанию: два чужих топовых эдита повторяют шаг за шагом. Если нужны детали из речи, пользователь присылает транскрипт или файл.

Порядок работы автора (тайм-коды из описания) и что делает скилл на каждом шаге:

| Шаг человека | Что делает скилл |
|---|---|
| Материалы для эдитов (0:25) | `fetch` по ссылке пользователя; `yt-search` и `film-lines` для поиска реплики; права и источник пишутся в метаданные |
| Проект и горячие клавиши | не нужны: монтаж идёт кодом, план хранится в `plan.json` |
| Работа с музыкой, маркеры (2:42, 3:22) | `beats FILE` находит доли, сильные доли это верхние 40% по энергии; они и есть маркеры |
| Обрезка клипов по маркерам (3:48) | `edit` режет шоты по сильным долям (~0.85-1.2 с) |
| Изменение масштаба (4:07) | зум на ударе (`editfx`), одно движение на шот |
| Кривые скорости (4:42) | velocity: быстро, зависание, быстро; после смены скорости шот подгоняется к биту заново |
| Субтитры (6:29) | пословные субтитры; для эдита только реплика и тезис |
| Финальные эффекты и звуки (7:21, 8:05) | `look`, вспышки с лимитом частоты, SFX на дропе, реплика громче музыки |

Идея для 2.0: когда пользователь даёт референс-эдит (ссылку на чужой топовый), сначала составь по нему "карту": длина, число шотов, куда падают дропы, где замедление, какие эффекты. Потом собери свой эдит на других кадрах по этой карте, не копируя чужие кадры и звук один в один.
