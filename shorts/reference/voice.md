# Голос: встроенный VoiceEngine (2.4)

Офлайн-озвучка русского и английского текста голосом любого пола и возраста (2-105 лет), сказочными и
мультяшными персонажами, с эмоциями, эффектами и диалогами на несколько ролей. Интернет, GPU и ключи не нужны.
Голоса оригинальные синтетические (смеси базовых тембров + моделирование возраста), не копии реальных людей.
Для `ru` и `en` он первый в цепочке `engine: auto`: любой план, мультик (`toon-*`), `stack` и персонаж получают его сами.

## Вес: как не запутаться (читать первым)
- Все модели (171 МБ в распакованном виде) лежат в ОДНОМ запечатанном архиве `assets/voice/voiceengine-models.tar.xz`
  (125 МБ, sha256 в `assets/voice/pack.json`). Это нормально, что скилл весит ~137 МБ: почти всё это голос.
- Архив НЕ открывать, не листать, не распаковывать руками, не читать `.onnx`, не переносить. Других TTS-моделей не качать.
- Первая озвучка сама распаковывает архив (10-20 с, проверка sha256) в первую доступную папку: `SHORTS_VOICE_MODELS`,
  `SHORTS_MODELS/voiceengine`, `<скилл>/.cache/models/voiceengine`, `~/.cache/shorts/voiceengine`, временная папка.
  Дальше папка переиспользуется. Сразу распаковать и проверить: `python3 tools/shorts.py voice-setup`.
- Код движка: `tools/shortskit/voiceengine/` (чужой код, не править и не читать целиком), вход для скилла один:
  `tools/shortskit/voice.py`. Всё, что нужно знать о голосах, выдают `voice --list` и `voice --describe`.
- Зависимости: `numpy`, `onnxruntime` (`requirements.txt`). Нет их: `python3 -m pip install numpy onnxruntime`.

## Одна команда
```bash
python3 tools/shorts.py voice "Ох, внучек, проходи скорее, пирожки стынут!" --attrs "ж, 90" -o out/babushka.mp3
python3 tools/shorts.py voice "Hey, I just turned nineteen!" -g m -a 19 -o out/guy.wav
python3 tools/shorts.py voice "Кто посмел войти в мою пещеру?" -p дракон -o out/dragon.mp3 --srt out/dragon.srt
python3 tools/shorts.py voice -f story.txt -p рассказчик -o out/story.mp3          # длинный текст из файла
python3 tools/shorts.py voice -s dialog.txt -o out/dialog.mp3 --save-lines out/lines  # сценарий на роли
python3 tools/shorts.py voice "Тест" --attrs "м, 85, устало" --describe             # что распознано
python3 tools/shorts.py voice --list                                                # голоса, персонажи, эмоции, эффекты
```
Вывод: JSON (`file`, `duration`, `words`, `timings`: `exact` | `estimated`, `voice`). `--srt` и `--words` пишут субтитры
и слова с таймингами. Формат по расширению: `.wav` (48 кГц), `.mp3`, `.m4a`, `.ogg`, `.flac` (через ffmpeg).

## Что просят -> атрибуты
| Просьба | Атрибуты (`--attrs` или поле `voice`) |
|---|---|
| 19-летний парень / девушка 20 лет | `м, 19` / `ж, 20` |
| бабушка 90 лет / дедушка 85, устало | `ж, 90` / `м, 85, устало` |
| мальчик 7 лет / девочка 5 / малыш 3 года | `м, 7` / `ж, 5` / `м, 3` |
| подросток 14 (ломается голос) | `м, 14` |
| мужчина 40, низкий голос | `м, 40, m2` |
| мультяшный персонаж / бурундук | `мультяшка` (можно `мультяшка, м`) / `белка` |
| дракон, великан, монстр, гном, медведь, лиса, злодей | `дракон` и т.д. |
| Баба-Яга, колдунья | `ведьма` |
| робот, пришелец, призрак | `робот`, `инопланетянин`, `привидение` |
| сказочник / диктор / ведущая | `рассказчик` / `диктор` / `ведущая` |
| шёпотом, радостно, грустно, сердито, испуганно | `шёпотом` и т.д. (эмоция) |
| по телефону, по рации, в пещере, эхо | `phone` / `radio` / `cave` / `echo` (эффект) |
| два похожих героя одного пола и возраста | разные имена: `ж, 30, voice=Оля` и `ж, 30, voice=Катя` |

Атрибуты через запятую в любом порядке: пол (`м`/`ж`, `male`/`female`), возраст (`90` или `90 лет`), голос
(`m1`-`m6`, `f1`-`f6` или `voice=ЛюбоеИмя` = свой стабильный тембр), персонаж, эмоция, эффекты (`phone+room`),
`speed=`, `pitch=`, `formant=`, `lang=`. Одно и то же имя всегда даёт тот же голос.

Готовые голоса: `m1` тёплый баритон-диктор, `m2` низкий бас, `m3` молодой светлый, `m4` энергичный, `m5` с хрипотцой,
`m6` мягкий разговорный (британский в EN); `f1` ясный дикторский, `f2` низкий бархатный, `f3` звонкий, `f4` молодой мягкий,
`f5` тёплый разговорный, `f6` уверенный деловой (британский в EN).
Персонажи: робот, великан, монстр, дракон, гном, мультяшка, белка, медведь, лиса, ведьма, злодей, привидение, инопланетянин,
рассказчик, диктор, ведущая. Эмоции: нейтрально, радостно, восторженно, грустно, сердито, испуганно, спокойно, устало,
торжественно, шёпотом (синонимы: бодро = радостно, энергично = восторженно, грозно = сердито). Эффекты: whisper, phone, radio, oldradio, megaphone, room, hall, cave, echo, robot, growl, ghost,
alien, crackle, underwater, radio_noise. Слова-роли сами задают пол и возраст: бабушка (ж80), дедушка (м80), мальчик (м8),
девочка (ж8), малыш (м4), парень (м20), мама (ж38), папа (м42), король, принцесса, пират... (`voice --list`).

Тонкая настройка: `--speed 0.85..1.15`, `--pitch 0.9..1.15` (высота), `--formant 0.9..1.15` (>1 детскее, <1 крупнее).
Слишком мультяшно: `pitch`/`formant` ближе к 1; сказочнее: `formant=1.2, pitch=1.3`.

## Голос в плане, мультике, персонаже
- `plan.json`: `"audio": {"voice": {"engine": "auto", "voice": "ж, 30, бодро", "speed": 1.05}}`. `engine: voiceengine`
  = только он (без запасных). Старые имена работают: `ru-male-1` = `диктор`, `ru-female-1` = `ведущая`, `ru-male-2` =
  `м, 26, m4`, `ru-female-2` = `ж, 25, f5` (то же для `en-*`). Имена голосов edge / Piper / OpenAI уходят своим движкам.
- `toon` (`episode.json`): `voice` эпизода = рассказчик; у героя свой голос в `cast`:
  `"masha": {"look": "kid", "name": "Маша", "voice": "ж, 7, voice=Маша"}`; сцена с `speaker` говорит его голосом,
  `tone` меняет подачу только этой реплики (`"tone": "шёпотом"`, `"сердито"`, `"эхо"`), `voice` в сцене перекрывает всё.
  `toon-check` подскажет, если герой говорит голосом рассказчика. Пример: `templates/toon/kids.json`.
- `persona`: голос ведущего в библии персонажа (`toon.voice`, например `ж, 72, voice=Валя`).
- Голос пользователя запоминается в `prefs` (`voice`), чтобы не спрашивать снова.

## Сценарий на несколько ролей (`voice -s dialog.txt`)
```text
# комментарий
@Бабушка Нюра = ж, 90
@Петя = м, 7
@Кот Борис = мультяшка, м
Рассказчик: Жила-была бабушка Нюра.
Бабушка Нюра: Петенька, иди кушать!
Петя (радостно): Иду, бабуля!          <- атрибуты в скобках только для этой реплики
[Кот Борис | эхо] Мяу!                 <- другая запись: [Имя | атрибуты] текст
(шёпотом) Тише, Борис.                 <- строка без имени = тот же говорящий
[пауза 1.5]                            <- тишина в секундах; пустая строка = пауза абзаца
```
Каждый персонаж получает свой стабильный голос по имени; пол угадывается по имени (Маша = ж), лучше задать явно.
`--save-lines DIR` кладёт каждую реплику отдельным файлом (для монтажа по сценам).

## Как писать текст
- Ударения и омографы модель ставит сама. Ошиблась: `+` перед ударной гласной (`з+амок`, `Ник+ита`) или строка в
  `memory/stress.txt` (твой словарь, живёт между роликами; формат как в `tools/shortskit/voiceengine/user_stress.txt`).
  Буква ё помогает.
- Числа, даты, время, деньги, проценты, единицы и частые сокращения читаются сами; редкие сокращения писать словами.
- `!` живее, `?` вопрос, `...` длинная пауза, пустая строка = абзац, `[пауза 2]` = 2 с тишины.
- Ребёнку короткие простые фразы; старику можно `устало` и многоточия.

## Тайминги слов и субтитры
Русский: слова берутся из длительностей самой модели (точные, `timings: exact`), субтитры и якоря `*_on` в мультиках
встают в слово. Английский: границы предложений точные, слова внутри распределяются по длине и реальным паузам
(`estimated`); если стоит faster-whisper, слова берутся из распознавания. QA меряет синхрон в обоих случаях.

## Цепочка и переключатели
`engine: auto` = VoiceEngine (ru / en) -> edge-tts -> ElevenLabs (ключ) -> OpenAI TTS (ключ) -> Piper (если установлен).
Другие языки (uk, de, es...) сразу идут в edge-tts. Принудительно: `SHORTS_TTS=voiceengine|edge|piper|...`;
выключить встроенный: `SHORTS_VOICEENGINE=off`; потоки: `SHORTS_VOICE_THREADS=2`. Кэш по тексту и голосу: повторный
рендер не синтезирует заново. Скорость: русский в 10-20 раз быстрее реального времени на 2 ядрах, английский в 1.5-2 раза;
память ~0.6 ГБ на язык.

## Если что-то не так
| Проблема | Решение |
|---|---|
| `VoiceEngine needs onnxruntime` | `python3 -m pip install numpy onnxruntime` |
| нет места для распаковки / папка только для чтения | `SHORTS_VOICE_MODELS=/путь/с/местом` и `voice-setup` |
| неверное ударение | `+` перед ударной гласной или `memory/stress.txt` |
| голос не тот | `voice ... --describe` покажет пол, возраст, персонажа, эффекты |
| ошибка espeak на английском (не Linux x86-64) | `apt install espeak-ng` / `brew install espeak-ng` |
| нужен «настоящий» голос знаменитости | нельзя: движок не клонирует людей, выбрать похожий по характеру синтетический |

Проверено в 2.4 в песочнице (Linux x86-64, 2 CPU): распаковка и sha256, `voice-setup` (ru + en), 12 голосов, персонажи,
эмоции, эффекты, сценарий на роли, мультик с голосами героев, рендер плана с субтитрами по словам. Не проверено: macOS,
Windows, ARM (английскому там нужен системный espeak-ng).
