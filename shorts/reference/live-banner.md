# Живая реклама

Включить `layout.bottom.animation.enabled=true`; без флага старый статичный путь сохранён.
Поля name, message, action, handle, qr_url, tagline, logo лежат в `layout.bottom`, а НЕ внутри
`layout.bottom.animation` (там только enabled, variant, cycle, safe_right). Иначе панель молча
покажет «VPN в Telegram»; `plan.py lint` даёт ошибку `banner_fields`. Пример: examples/advertising/video-training/plan.json.
Задать name, message (по умолчанию «VPN в Telegram»), action («Открыть бота»), handle,
qr_url (полная точная рекламная ссылка), logo при наличии проверенного актива.
animation.variant: quattro или bob; cycle >=8 (по умолчанию 12 секунд).
Геометрия нового компонента: минимум 480x240, для полной композиции с QR рекомендован
реальный размер 1080x384; очень тесный макет отклоняется, не уменьшается молча до микротекста.

Движок `engine/banner.py`: независимые слои logo/title/message/cta/accent, ключевые кадры
{t,value,ease}, easing linear/out_cubic/in_out; появление, раскрытие названия, отдельный CTA,
короткий акцент, спокойное удержание QR, повтор. Пользовательские tracks задают прогресс
появления отдельных слоёв. Логотип не деформируется. Без актива монограмма - **типографика**,
не «официальный логотип». Иерархии Quattro и Боб различаются цветом и графическим рельсом.

QR неподвижен весь цикл: целочисленный размер модулей, белое поле в 4 модуля, полный URL.
quiet_phase не доказывает реальную считываемость: проверить после MP4 на телефоне;
при необходимости увеличить цикл, размер или изменить размещение. Нарисованный CTA
не является кликабельной кнопкой. Ник остаётся читаемым независимо от QR.

Результат рендера содержит graphics/banner.json с ROI элементов. `qa/banner.inspect_video`
сравнивает **только ROI рекламы** и декодирует QR из нескольких фаз финального MP4.
Движение основного видео не засчитывается. Проверить на 360/390px и с актуальным
интерфейсом площадки; низ кадра не считается безопасным по умолчанию. Если нижняя область
закрыта UI, перестроить композицию или выбрать другую площадку, а не принять дефект.

Происхождение: AffTrends (2026-07) - скриншоты встроенных баннеров; они не подтверждают
анимацию. Zion & Zion (2019) - рекомендации для display: движение по очереди, иерархия,
короткий смысл/CTA, контраст. Лимит 15 секунд display не является законом Shorts.

Для резерва под интерфейс `bottom.reserve_bottom_pct` поднимает рекламную область,
оставляя незанятую полосу снизу; это уменьшает центр, поэтому проверить >=55%.
`animation.safe_right` сдвигает неподвижный QR от правых кнопок. Значения резерва -
параметры макета, не гарантии безопасности конкретного приложения. Наложение реального
интерфейса обязательно; консервативный старый safe-zone может по-прежнему не принимать макет.

## Явный текст текущего продукта (v3.4)
Заполнять name/message/action явно; встроенные fallback «VPN в Telegram»/«Открыть бота»
оставлены только для совместимости старых планов. Не брать их для нового продукта.
cycle >=8 - ограничение AnimatedBanner, не универсальное время показа рекламы.
Для рекламного проекта хранить campaign.json рядом с результатом и advertising=true в release.json.
Рендер панели сам по себе не является проверкой оффера и разрешением запуска.
