# Видео кодом (2.4): 4 приёма

Модель не рендерит видео, она пишет код, который его рисует: HTML-страница с canvas / SVG / CSS, p5.js, Three.js
(или композиция Remotion). Скилл открывает страницу в браузере без экрана, шагает по кадрам через `window.seek(t)`,
пишет MP4 и кладёт сверху голос (VoiceEngine), музыку и субтитры. Монтажка и платные сервисы не нужны.
Так сделана большая часть роликов из индекса claudevideo.org (кинетическая типографика, UI-морфинг, объяснялки, 3D).

## Быстрый старт
```bash
python3 tools/shorts.py code-new projects/code1     # scene.html + plan.json + fonts/ + vendor/ (p5.brush, thinking-orbs) + brand.css
# 1) SCENE в scene.html: kicker, title, steps (cue = слово озвучки, orb = состояние); 2) say в plan.json
python3 tools/shorts.py validate projects/code1/plan.json
python3 tools/shorts.py all projects/code1/plan.json --out projects/code1/out   # render + qa (+ meta, cover)
```
Предпросмотр: открыть `scene.html` в браузере (крутится по кругу). Выдача как у любого ролика: `pack`.
Эталон страницы со всеми правилами ниже: `templates/code-video/scene.html` (проверен рендером и QA).

## Приём 1. Анимация как код -> MP4
Контракт страницы (без него кадры не совпадут с голосом):
- сцена сразу 1080x1920 (вертикаль не кропается из 16:9), шрифты локальные (`fonts/`, OFL), ждать `document.fonts.ready`;
- `window.seek = (t) => { ... }` рисует кадр в момент `t` секунд (можно вернуть Promise); старое имя `window.__seek` тоже работает;
- кадр зависит только от `t`: без `Date.now()`, `performance.now()`, таймеров и `Math.random()` (случайность только
  `rng(seed)` от `seed` сцены); CSS-анимации и GSAP вести от `t` (`tl.seek(t)`, `anim.currentTime`), а не от часов;
- скилл до скриптов страницы кладёт `window.SHORTS`: `length`, `fps`, `in`, `start`, `seed`, `words` (`[{w, s, e}]` слова озвучки
  с таймингами), `beats`, `strong`, `tempo`, `drop`, `brand` (цвета и шрифты плана);
- `type="module"` или importmap (Three.js как ES-модуль): страница сама отдаётся с локального сервера из своей папки
  (`"serve": true` в источнике включает это вручную); всё подключать из `vendor/`, не с CDN;
- зоны кадра: важный текст в безопасной зоне y 288-900, x 120-888 (пересечение Shorts / TikTok / Reels,
  `schema/safe_zones.json`); полоса субтитров 928-1248 (её рисует скилл, в неё ничего не ставить); ниже 1248 только
  декор, который не жалко закрыть интерфейсом площадки (в шаблоне орб и эквалайзер); первый кадр уже с хуком
  (заголовок виден с 0.0 с); пустых зон больше половины кадра нет (QA `layout` это ловит).
Кодирование делает скилл: H.264, `yuv420p`, `+faststart`, CRF 18, 30 к/с (как советует гайд claudevideo.org
`/guides/html-animation-to-mp4`). В плане сцена: `"source": {"type": "html", "ref": "scene.html", "seed": 7}`,
`"layout": {"mode": "center_only"}`; свои субтитры на странице = `"captions": {"enabled": false}`.

## Приём 2. Голос
Голос делает VoiceEngine (`reference/voice.md`): `audio.voice.voice` = `"м, 32, m4"`, `"ведущая"`, `"ж, 25, бодро"`.
Слова голоса с таймингами приходят в `SHORTS.words`: шаг анимации начинается на своём слове (`steps[].cue`),
так картинка идёт за речью. Нет слова в озвучке: шаг встаёт на следующий сильный бит.

## Приём 3. Музыка
- Пользователь не дал трек и не просил тишину: `"music": {"source": "auto", "mood": "tech"}` (по умолчанию). Скилл сам ищет
  на YouTube по настроению и теме, берёт инструментал без вокала, скачивает нужный кусок, ставит под голос, автора пишет в
  описание (`reference/audio.md`). Просили без музыки: `"music": "none"`.
- Свой трек: `python3 tools/shorts.py beats трек.mp3 --js beats.js --main 9` и `"music": {"source": "трек.mp3"}`.
  Человек говорит, какой бит несёт главное движение: `--main 9` (9-й бит), `--main bar3` (3-я сильная доля),
  `--main 12.5` (секунда), `--main drop` (дроп). В странице это `BEATS.main`; без него главное движение идёт на дроп,
  иначе на 5-й бит. `--start` / `--length` режут трек под ролик.

## Приём 4. Бесплатный старт и чужие находки
- Без кода и без скилла: в чате Claude попросить артефакт «HTML-анимация 9:16 про ...» (ниже шаблон), посмотреть,
  дать 2-3 круга правок («сцена 2 перегружена», «держи финальную карточку на секунду дольше»). Готовый HTML положить
  в папку `code-new`, привести к контракту (seek(t), SHORTS, зоны) и собрать скиллом с голосом и музыкой.
- Эффекты с GitHub: `python3 tools/shorts.py fx-get p5.brush --to ПАПКА` (живые мазки, MIT), `fx-get thinking-orbs`
  (9 «думающих» орбов, MIT), любой репозиторий `fx-get github.com/OWNER/REPO` или `fx-get npm:ИМЯ`. Копия ложится в
  `vendor/` с LICENSE и SOURCE.md; репозиторий без лицензии не берётся. Подробно: `assets/fx/README.md`.
- Свой стиль: человек кидает в чат `brand.md` (цвета, шрифты, правила движения). Сохранить файл и выполнить
  `python3 tools/shorts.py brand-md import brand.md`: в памяти (`memory/brand/`) появятся brand.json, brand.css и копия,
  `code-new` и планы берут их сами. Пустой бланк: `brand-md template -o brand.md`, проверить понятое: `brand-md show`.
  Правила движения из brand.md (длительности, easing, что никогда не двигается) читать перед кодом сцены и соблюдать.

## Разбор чужих роликов: claudevideo.org
Неофициальный индекс роликов, сделанных кодом через Claude: 1276 роликов, у 457 есть полный промпт автора.
- Страница ролика `/videos/<slug>`: `THE PROMPT` (что просил автор), `OUR NOTE` (что показано и чем цепляет),
  теги `LOOK` (character-animation, kinetic-type, 3d, music-visualizer...). Фильтр `Has prompt` на главной.
- Как пользоваться: найти 3-5 роликов с похожим LOOK и темой, выписать из промптов длительность, сцены с таймингами,
  палитру, шрифт, технику (GSAP / canvas / SVG / Three.js), что держит внимание по OUR NOTE. Взять приёмы и структуру,
  не копировать ролик. Промпт принадлежит автору: если строишь на нём, указать автора в описании.
- Наблюдения индекса (`/guides/claude-opus-5-5-video-prompts`): медиана промпта 28 слов, 58% задают длительность;
  подробные ТЗ (150-500 слов: размер сцены, длительность, палитра, сцены по секундам) дают заметно более сильные ролики,
  чем однострочники; вирусный бриф «покажи, какой ты моушн-дизайнер» уже перенасыщен (87 копий).
- Ролики и промпты принадлежат авторам; сам индекс не связан с Anthropic.

## Шаблон запроса (по мотивам шаблона claudevideo.org, под шортс со скиллом)
```text
Сделай один самодостаточный HTML-файл (без внешних ресурсов): вертикальная анимация 9:16 на фиксированной
сцене 1080x1920, [20] секунд, потом держит последний кадр.
Тема: [о чём ролик одним предложением]
Зритель и тон: [для кого; уверенно / игриво / технично]
Визуальная система (из brand.md): палитра [2-4 цвета], шрифт [например, жирный гротеск для заголовков],
движение [резкие входы 300-500 мс, без отскоков, жёсткие склейки между сценами]
Сцены:
1. 0:00-0:03 [хук: заголовок виден с первого кадра]
2. 0:03-0:10 [середина: 2-3 шага]
3. 0:10-0:17 [развязка]
4. 0:17-0:20 [финальная карточка, переход в начало для зацикливания]
Техника: [canvas / SVG / Three.js / GSAP]. Каждый кадр детерминирован: функция window.seek(t) рисует кадр в момент t,
без Date.now и Math.random. Текст только в зоне y 290-900, x 120-890; полосу 928-1248 оставь пустой под субтитры,
ниже 1250 только декор.
```

## Remotion и HyperFrames (по желанию)
Если у человека стоит Remotion (`remotion render`) или HyperFrames, их MP4 идёт в план как видео-источник
(`"source": {"type": "video", ...}`), голос, музыка и субтитры как обычно. Базовый путь скилла (HTML + seek) работает без npm.

## Проверка перед выдачей
`qa DIR` (синхрон голоса, громкость, пустые зоны, текст в безопасных зонах), просмотр целиком со звуком,
контакт-лист `out/contact.png`. Частые ошибки: анимация от реального времени (кадры дёргаются, не совпадают со словами),
шрифт с CDN (в рендере подставился другой), текст в полосе субтитров, пустой первый кадр, белые вспышки на склейках.
