# Эдит: монтаж событий, не одинаковых отрезков

Определить героя, конфликт/настроение и эмоцию. Просмотреть весь доступный материал,
создать банк шотов с source in/out, действием, крупностью, движением, качеством,
фокусом/кропом, смысловой ролью и браком. Выбрать точный музыкальный фрагмент.
Описать вход, развитие, акцент/дроп и завершение. Маркеры выставлять по слышимым
музыкальным событиям, не только по сетке BPM. Автоматические onset - кандидаты.

Сначала шоты по драматургии: самостоятельный вход -> подготовка -> отдача -> завершение.
Совмещать с акцентом склейку либо удар/поворот/взгляд/движение/смену крупности.
Чередовать плотность и удержания сильного кадра. Для каждого speed ramp, punch-in,
маски, match cut и перехода объяснить роль. Не применять эффект на каждый стык.
Не ограничивать осмысленную режиссуру количеством эффектов.

Слоумо низкого FPS проверять в движении, optical flow - на лицах/руках/контурах.
При деформации изменить скорость/шот, не прятать дефект. Согласовать цвет, не терять
детали тёмных сцен. Связать конец визуальной и музыкальной фразы; fade не делает
случайную остановку завершением. Узнаваемое лицо само по себе не является хуком.

обязательны отдельно от анализа громкости и битов. Без слуховой приёмки выпускать превью.
