# Мультики кодом: toon (2.3, голоса и музыка 2.4)

Рисованные 2D-ролики без платных сервисов и без картинок со стороны: персонажи, места, схемы, плашки и субтитры
рисует код (canvas в headless Chromium), голос встроенный VoiceEngine (2.4: у каждого героя свой, запасные edge-tts и Piper),
тайминг сцен по реальным словам голоса, музыка находится сама (2.4).
Подходит для историй «а я бы выжил?» (блэкаут, зомби, каналы в духе «Жив или нет?», «ВЫЖИВИ»), простых детских
мультиков, объяснялок с ведущим, длинных роликов 16:9 с главами и для рисованного ИИ-ведущего (`reference/persona.md`).

## Быстрый старт (5 команд)
```bash
python3 tools/shorts.py toon-new episodes/blackout -t blackout   # заготовка: blackout | zombie | kids | explainer | long
# правка episodes/blackout/episode.json: say / set / actors / scheme по сценам
python3 tools/shorts.py toon-check episodes/blackout     # имена, якоря, темп, правила канала (exit 1 = ошибки)
python3 tools/shorts.py toon-preview episodes/blackout   # голос + тайминг + build/sheet.jpg (кадр на сцену): СМОТРЕТЬ
python3 tools/shorts.py toon-render episodes/blackout --draft   # 540x960, 24 к/с, быстро: проверить движение и звук
python3 tools/shorts.py toon-render episodes/blackout    # 1080x1920, 30 к/с + cover.jpg + build/sheet.jpg
```
Ещё: `toon-catalog` (все имена), `toon-catalog --examples gauge` (готовый JSON из шаблонов), `toon-cast DIR` (лист героев).
Длинный ролик дополнительно пишет `build/chapters.txt` (главы YouTube для описания).

## Какой шаблон брать
| Задача | Шаблон | Что внутри |
|---|---|---|
| Выживание, катастрофа + место, 60-90 с | `blackout` | 27 сцен ~81 с: часы «ДЕНЬ 1 - 18:04», разрез дома, схема лестницы, давление в трубах, чек-лист |
| Зомби / угроза снаружи | `zombie` | ~60 с: толпа идёт, вид сверху с маршрутом, баррикада, вентиляция |
| Детский мультик, «почему?» | `kids` | ~55 с: светлая тема `sky`, радуга, призма, викторина, `audience: kids` |
| Объяснялка с ведущим | `explainer` | ~52 с: доктор-ведущий + герой, timeline / gauge / bars / compare |
| Длинный 16:9 с главами | `long` | ~89 с образец: 3 главы, карточки глав, концовка 12 с под конечные заставки |
Новая история = взять ближайший шаблон и заменить текст и места. Не писать эпизод с нуля.

## Эпизод (episode.json)
Верх: `title`, `slug`, `aspect` (`9:16` | `16:9` | `1:1` | `4:5`), `lang`, `voice` (голос рассказчика: атрибуты VoiceEngine
`"ж, 30, f5"`, `"рассказчик"` или старые `ru-male-1` | `ru-female-1`), `engine` (`auto` | `voiceengine` | `edge` | `piper`), `speed` (1.0-1.12), `fps`, `time` (палитра по умолчанию), `cast`, `scenes`.
- `style`: `captions` (`caps` = 1 строка до 3 слов, `sentence` = 2 строки, спокойнее, `off`), `caption_size`, `grain`, `vignette`,
  `outline`, `scheme_bg` (тема схем: `blue` | `paper` | `dark` | `sky`).
- `cast`: `{"max": {"look": "hero", "name": "Макс", "hair": "#3B2A22", "hair_style": "short", "detail": "scarf"}}`; любой цвет
  внешности можно переопределить (`top_color`, `hat`, `hat_color`, `detail_color`, `bow`).
  2.4: `voice` героя (`"ж, 7, voice=Маша"`, `"мультяшка, м"`, `"дракон"`): сцена с `speaker` говорит его голосом,
  `tone` в сцене меняет подачу одной реплики (`"шёпотом"`, `"сердито"`, `"эхо"`), `voice` в сцене перекрывает всё.
  Атрибуты и персонажи: `reference/voice.md`.
- `audience: "kids"` включает детские правила, `format: "long"` правила длинного ролика, `chapter_card` (`full` | `corner`),
  `clock_on_schemes` (часы и на схемах), `brand` (тихая подпись справа сверху).

Сцена: `say` (текст голоса, `*слово*` = акцент в субтитрах), `set`, `shot`, `actors`, `props`, `hud`, `scheme`, `fx`,
`camera`, `transition`, `clock`, `chapter`, `endscreen`, `accent`, `dark` (0..1), `shake`, `dur` / `pad` (только для сцен без
голоса), `note` (заметка себе). Чего нет в сцене, код дополняет сам: место и время наследуются (после схемы на весь
кадр - снова прошлое место), камера и переход не
повторяются подряд, часы переносятся и перелистываются при смене, крупность выбирается по смыслу.
- `set`: строка или `{"id": "stairwell", "time": "blackout", "floor": 19}`. 15 мест: plain, room, kitchen, facade, stairwell, dacha,
  forest, street, mall, train, bunker, roof, beach, road, meadow. Палитры `time`: day, dusk, night, blackout, winter, toxic, paper, kids.
  Опции мест смотреть так: `toon-catalog --examples floors` (фасад), `variant` (комната), `lights_out_on`.
- `actors`: `{"id": "max", "pose": "hold", "hold": "bucket", "emotion": "worried", "face": "front", "gaze": "camera", "at": 0.42}`;
  `at` = место по ширине 0..1; `acts` / `feel` = смена позы / эмоции на слове: `"acts": [{"on": "ловушка", "pose": "hands_up"}]`;
  `path` = проход `[[сек, x, null], ...]`. 34 позы, 15 эмоций, 48 предметов: `toon-catalog`.
- `props`: предметы и толпы: `{"id": "crowd", "n": 6, "area": [x0, y0, x1, y1], "look": "zombie", "walk": 0.05}`.
- `shot`: `wide` | `medium` | `close` или `{"type": "close", "on": "max"}`. Крупные планы держат лицо в полосе 0.33-0.60 высоты.
- `camera`: drift, static, push, pull, pan_left, pan_right, tilt_up, tilt_down, crash. `transition`: cut, fade, flash, iris, slide, whip, zoom
  (`flash` только на шоке).

### Якоря на словах (главный приём синхрона)
Любой ключ, который кончается на `_on`, становится временем этого слова в сцене: `"lights_out_on": "пропал"`,
`"split_on": "белый"`, `"route_on": "крыша"`. В плашках, пунктах схем и `acts` то же самое делает `"on": "слово"`.
Пара: `split_on -> split_t`, `break_on -> break_t`, `path_on -> path_t`, `route_on -> route_t`, `water_on -> water_t`,
`vent_on -> vent_t`, `reveal_on -> reveal`, `t_on -> t`. Слово ищется в этой же сцене (начало слова, без регистра).

### Плашки (hud) и схемы (scheme)
HUD поверх сцены: clock, counter, tape, ribbon, stamp, plate, callout, title, chapter, question, bar, timer, arrow, circle, label, brand.
Схема занимает кадр целиком (герой уходит, в конце сцены код возвращает историю): cutaway (разрез дома), stairs, gauge
(бак, давление: `kind`, `from`, `to`, `timer`), map (кольца и маршрут), radius, chain (цепочка поломок, `break_on`),
topview (план квартиры с маршрутом), checklist (пункты с `on`, `swatch`), compare, bars, counter, quiz (`reveal_on`), timeline,
steps, closeup (предмет крупно), card, prism (луч и радуга, `split_on`). Точный JSON: `toon-catalog --examples ИМЯ`.
FX: rain, snow, dust, embers, fog, smoke, sparks, shards, leaves, flood, confetti, speedlines, stars, rainbow, sparkle, spray,
lightning, flicker, alarm, blackout.

## Кадр: полосы (9:16)
| Полоса (доля высоты) | Что там |
|---|---|
| 0.09-0.30 | часы, плашки, заголовки (HUD), бар «Силы» |
| 0.33-0.60 | лица (крупные планы, `gaze: camera`) |
| 0.61-0.70 | субтитры (`caption_y` 0.655) |
| ниже 0.76 | только фон: интерфейс Shorts / TikTok |
В 16:9 одиночный герой в среднем и крупном плане стоит по правилу третей (`"center": true` отключает),
схемы заканчиваются над субтитрами. `toon-check` предупреждает, если плашка попала в зону субтитров.

## Темп и правила канала (проверяет `toon-check`)
- Хук: первая сцена до 3.5 с, в первом кадре герой, заголовок или схема; финал = вопрос в комментарии или петля к началу.
- Новый ракурс каждые 2-4 с (в длинном 3-6 с); одна камера и один переход не подряд; не больше 5 сцен в одном месте
  (7, если есть 3 разные крупности): потом схема, крупный план или другое место.
- Речь 2.4-2.9 слова/с; тишина в сцене только с действием. 1-2 ленты (`ribbon`) и не больше 3 «погасаний» на ролик.
- Шортс 45-90 с. Длинный: сцена до 12 с, повторный крючок (вопрос, штамп, схема, глава) каждые 30-45 с, главы каждые
  60-120 с (обязательны после 120 с), холодный старт до 8 с, концовка `endscreen` 5-20 с и только последней сценой.
- Дети (`audience: kids`): никаких «подпишись / лайк / пиши в комментариях», при загрузке «Для детей», без рекламы и ссылок.

## Сценарий за 6 шагов (подходит любой истории)
1. Катастрофа или вопрос + место + герой («блэкаут, ты на 20-м этаже»). Неочевидный поворот («все бегут вниз, а надо остаться»).
2. Хук одной фразой, затем 5 кусков: что случилось, первая ошибка, правильное действие, усложнение (ночь, день 2),
   развязка + вопрос зрителю. Время на экране (`clock`) двигает историю.
3. На каждый факт схема или крупный предмет (gauge, cutaway, checklist), на эмоцию крупный план и `feel`.
4. `toon-check` до нуля ошибок, `toon-preview`, глазами по `build/sheet.jpg`: лица не под плашками, текст не режется.
5. `toon-render --draft`, посмотреть целиком со звуком, поправить, финальный рендер.
6. Упаковка как у любого ролика: `pack` (названия, три описания, три обложки); `cover.jpg` уже есть.

## Звук
Голос по умолчанию встроенный VoiceEngine (2.4, офлайн, без интернета; запасные edge-tts и Piper; кэш в `.cache/tts`).
Музыка (2.4): `"music": "auto"` в шаблонах = трек найдётся на YouTube по настроению эпизода (детям весёлый, зомби
напряжённый), встанет под голос, автор уйдёт в описание; YouTube заблокирован = ролик без музыки + команда для компьютера
пользователя в `music.json`. Свой трек: `"music": {"file": "track.mp3", "gain": -18}`; настроение: `{"source": "auto",
"mood": "calm"}`; без музыки только по просьбе: `"music": "none"`. Синтетические SFX не добавляются (правило 2.2).
Громкость -14 LUFS.

## Производительность
Черновик ~20-50 мс на кадр (2 CPU), финал 1080x1920 30 к/с: 80 с ролика ~3-4 мин с `--workers 2`. Edge-tts иногда отвечает
«No audio was received»: повторить команду, готовые фразы берутся из кэша.

## Если что-то не так
| Симптом | Что сделать |
|---|---|
| `unknown pose / item / scheme` | имя из `toon-catalog`, пример из `toon-catalog --examples` |
| «word not found» у якоря | слово должно быть в `say` этой же сцены; брать начало слова без окончания |
| Плашка на лице | поднять `y` или сменить `shot`; лица живут в 0.33-0.60 |
| Длинное слово в субтитрах | код сам уменьшает шрифт; лучше писать числа словами («двенадцать») для голоса |
| Сцена «висит» | разбить, добавить `acts`, камеру или плашку |
| TTS смешал движки | повторить запуск (кэш хранит хорошие фразы) или задать `engine` |
| Герой говорит голосом рассказчика | дать ему `voice` в `cast` (`toon-check` подсказывает) |
| Музыки нет в ролике | `music.json` рядом: `status` и готовая команда; файл положить рядом и указать `music.file` |
