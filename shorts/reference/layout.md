# Раскладка кадра 1080x1920

| Режим `layout.mode` | Панели |
|---|---|
| `three` | верх (до 20%) + центр (от 55%) + низ (до 20%) |
| `top_center` | верх + центр |
| `center_bottom` | центр + низ |
| `center_only` | только центр (эдиты, нарезки) |
| `band` (1.3) | чёрные поля + полоса картинки в середине (от 1056 px) + плашка темы `title_bar` ("кинобаст") |

Второе окно внутри центра (sludge 50/50, "верх движ, низ контент", картинка в картинке): `layout.split`, `reference/vfx.md`.
Фон на весь кадр + карточка поста (раскладка C, история Reddit поверх геймплея): сцены `video` с `ref: "bg:auto"` +
`overlays.post`, `reference/vfx.md`.

- Верх: **живое видео с движением**, без пустых мест. Источник:
  - `loop:auto` (по умолчанию): своя процедурная петля в цветах бренда, выбирается по теме:
    `loop:race` (забег), `loop:spin` (вращение 3D-фигур), `loop:code` (дождь кода), `loop:runner` (раннер с большим героем).
    Подробно: `assets/footage/SOURCES.md`.
  - свой файл пользователя (геймплей, записи проектов): `prefs set panels='{"top": "файл.mp4"}'`, зацикливается;
  - `bg:auto` / `bg:<id>` (1.3): геймплей из библиотеки фона (GTA мега-рампа, Minecraft паркур), без звука;
    окно с движением в каждой секунде и кадрирование выбирает код, подпись автора идёт в описание (`reference/vfx.md`);
  - `html:файл.html` (снимается кадр за кадром); `color:#hex` = пустая панель, QA провалит.
  QA меряет на готовом ролике: за секунду меняется от 30% пикселей панели, тёмной пустоты не больше 25%.
- Центр: главное (сайт, HTML-сцена, эпизод). Всегда от 55% высоты.
- Низ: фирменная полоса (логотип словом, ссылка, ник). Помни: в Shorts нижние 672 px закрыты интерфейсом,
  поэтому низ это подпись бренда, а **реклама живёт во вспышках из центра** (`reference/qr.md`).
- Сетка 8 px, одна кривая плавности (ease-out cubic) на весь ролик.

## Рабочая (safe) зона
`schema/safe_zones.json`, для нескольких платформ берётся пересечение (самое строгое):

| Платформа | верх | низ | лево | право | доп. | источник |
|---|---|---|---|---|---|---|
| YouTube Shorts | 288 | 672 | 48 | 192 | - | Google Ads, шаблон вертикального видео |
| TikTok | 240 | 660 | 120 | 120 | колонка кнопок x 780-1080 от y 840 | TikTok Ads, официальный шаблон In-Feed (Feed.png 2880x5120, измерен по пикселям) |
| Reels | 269 | 672 | 65 | 65 | - | Meta Ads Guide (Reels, engagement): 14% / 35% / 6% |

Внутри зоны: метка-заголовок сцены сверху, вспышки CTA в середине, субтитры в нижней трети.
Для TikTok полоса субтитров и вспышек сдвинута левее колонки кнопок автоматически.
