# Источники сырья (адаптеры)

Каждый адаптер получает сцену плана и отдаёт клип центральной панели точного размера и длины.

## site
Сайты и сервисы. Playwright + Chrome, видимый курсор с кольцом клика, запись через DevTools screencast
(чёткие кадры с метками времени), плавный зум камеры на клик (1.28x, ease-out, держит 1.4 с).
1. `site-probe URL`: статус, защита, скриншот 1080x1232, список кликабельных элементов с селекторами.
2. Выбери 2-4 действия, которые показывают пользу (поиск -> результат), без лишней беготни.
3. Защита от ботов (капча, Cloudflare, "проверка браузера", HTTP 401/403/429) -> сцена пропускается,
   в отчёте `skipped: причина`. Не обходим. Скажи пользователю и предложи замену.
4. Известно: `builditapp.com` закрыт защитой; клик по 3D-модели на cadlookup.com роняет вкладку в headless
   (движок сохраняет кадры до падения и пишет об этом).

## html
Локальный HTML (игра, анимация, three.js, фильм в одном файле). Видео кодом с голосом и музыкой (2.4):
`reference/code-video.md`, заготовка `code-new DIR`. Детерминированный режим по умолчанию:
1. `window.seek(t)` или `window.__seek(t)` в странице (лучше всего: точное время; Promise дожидается);
2. `window.frame(dt)` (шаг симуляции, физика шагами до 1/60 с);
3. иначе подменяется время: `performance.now`, `Date`, `requestAnimationFrame`, таймеры, CSS/Web-анимации,
   `Math.random` с seed. Любая страница снимается кадр за кадром, повторный рендер даёт те же кадры.
`speed` замедляет и ускоряет без рывков (виртуальное время). `mode: "realtime"` = запись в реальном времени
(для страниц, которым нужен настоящий WebGL-цикл), потом ретайм. Звук HTML не пишется: голос, музыка и SFX из плана.
2.4: до скриптов страницы кладётся `window.SHORTS` (`scene`, `length`, `fps`, `in`, `start`, `seed`, `words` = слова голоса
с таймингами, `beats`, `strong`, `tempo`, `drop`, `brand`), чтобы анимация шла за словами и битами. Страница с
`type="module"` или importmap отдаётся с локального сервера из своей папки (`file://` модули не грузит); принудительно
`"serve": true` в источнике. `seed` в источнике = зерно `Math.random` страницы и `SHORTS.seed`.

## video
Длинное видео пользователя (файл или ссылка). `clips --video файл -n 3 --length 30` строит планы:
окна по громкости, плотности склеек, речи (faster-whisper даёт слова) и heatmap (если ссылка YouTube),
начало по началу фразы, без разрезов внутри слова, 3 сцены с зум-ударом на стыках, звук оригинала,
субтитры из транскрипта. Кроп в вертикаль по `crop_x` (0..1, по умолчанию центр).

## film
Фильм или ролики с YouTube. `reference/edits-film.md`.

## text
Тема или текст. Ты пишешь сценарий (`say`), а кадр = кинетическая типографика: фразы (`|`, перевод строки,
`->`, конец предложения) крупно по очереди, фон чередуется (фон бренда / его оттенок), `*слово*` = акцент.
Свободная зона не залезает под субтитры и метку. Если есть картинки (`source.images`), они идут фоном с затемнением.
Лучше всего давать кадры из проектов пользователя.

## images
Скриншоты в движении: медленный зум и панорама к `focus` [x, y], несколько картинок делят сцену,
`points: [[x, y, t], ...]` рисуют кольца "клика" (координаты 0..1 картинки, t в секундах сцены).
