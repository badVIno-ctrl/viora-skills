# Пакет без служебного мусора

ОПИСАНИЕ.txt: только готовый текст для зрителя, проверенные ссылки и смысловые таймкоды.
ОТЧЁТ.md: статусы, замены, ограничения, источники и внутренние замечания.
Не писать «полное видео на канале» без проверенного metadata.full_video_url.
Не помещать TODO, шаблоны, инструкции исправить обложку или противоречивую атрибуцию музыки.

Таймкоды по финальному MP4: `00:00 - Название блока`. Не SRT, без миллисекунд/стрелок.
Не делать псевдоглавы по каждой реплике. После перемонтажа пересчитать всё.
Техническая проверка проверяет формат/порядок/длительность; совпадение с реальным смысловым
переходом проверяет редактор. Списки таймкодов поддерживаются и для короткого пути.
YouTube Help 9884579: ручные главы требуют 00:00, минимум 3 меток по порядку,
минимум 10 секунд на главу и доступ к функциям; отображение доступно не всегда.
Это не обещание нативных кликабельных глав в Shorts.

Экспорт SRT ограничивает 200ms хвост началом следующего блока. Проверить слова и
синхронизацию по звуку; исправление пересечения не доказывает точность ASR.
