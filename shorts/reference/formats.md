## Как выбирать между похожими путями
- Есть живой исходник (интервью, фильм, геймплей): stack / edit. Нет исходника, есть идея или текст: toon (персонажи,
  история) или code-video (типографика, схемы, интерфейсы, абстрактная графика, 3D-объекты).
- Нужен «живой» реалистичный человек, которого нет: только persona `ai` с раскрытием ИИ, никогда не выдавать за реального.
- Регулярная серия (каждый день): toon, он бесплатный и одинаковый по стилю; AI-видео для отдельных «вау»-выпусков.
- Детям: toon `kids`, без призывов и рекламы; реалистичных ИИ-людей детям не делать.

## Слабой модели: порядок без исключений
1. Выбрать строку таблицы. 2. Взять шаблон (никогда не писать с нуля). 3. Заменить только текст, места, имена.
4. Команда `*-check` (для code-video `validate`) до нуля ошибок. 5. Превью, посмотреть картинку (sheet / кадры). 6. Рендер. 7. `pack`.
