# Выдача пользователю: одна чистая папка (v3.6)

Проблема v3.5: в архив попадали `.srt`, `.timeline.json`, `technical-report.json`, а названий и описаний не было.
Человек не должен искать нужное среди служебных файлов.

## Команда
`python tools/shorts.py deliver deliver.json --out ГОТОВО --zip`

## deliver.json
```json
{
  "set_title": "4 шортса",
  "items": [
    {"video": "out/s1/final.mp4",
     "title": "Название ролика",
     "description": "Готовый текст описания. Реклама. Ссылка: https://...",
     "pinned_comment": "...",
     "hashtags": ["#шортс"],
     "cover": "out/s1/cover/cover-A.png",
     "ad": {"name": "Quattro VPN", "url": "https://..."},
     "sources": ["https://..."],
     "to_check": ["Прослушать речь на стыках", "Права на музыку не проверены"],
     "service": ["out/s1/captions.srt", "out/s1/qa.md"]}
  ]
}
```
`"from": "out/s1"` подтягивает рекомендованное название, описание, закреп и обложку из metadata.json,
явные поля имеют приоритет.

## Что получится
```
ГОТОВО/
  01-Название ролика.mp4
  01-Название ролика-обложка.png
  02-....mp4
  ОПИСАНИЯ.txt          <- названия, описания, закрепы, хэштеги, ссылки, источники, что проверить
  _служебное/           <- srt, qa, json; в zip НЕ входит (флаг --with-service добавит)
ГОТОВО.zip
```

## Что блокирует выдачу (exit 1)
нет названия или описания; название > 100 знаков; размер не 1080x1920; нет звука; длительность > 180 с;
в ролике реклама, а в описании нет слова «Реклама» или точной ссылки.

## Правила текста
- Описание написано для зрителя, готово к копированию, без TODO и внутренних кодов.
- «Что проверить» - простыми словами (прослушать, права, маркировка), не списком флагов.
- В чате: рекомендованные названия + файл. Не пересказывать технический отчёт.
