# Звук

## Голос (TTS)
**2.4: встроенный VoiceEngine первый.** Цепочка `engine: auto`: VoiceEngine (офлайн, ru / en, любой пол и возраст 2-105,
персонажи, эмоции, эффекты, диалоги: `reference/voice.md`) -> edge-tts (бесплатно, неофициально, бывает пустой ответ:
6 попыток с паузой) -> ElevenLabs (`ELEVENLABS_API_KEY`, `ELEVENLABS_VOICE_ID`, с таймингами символов) -> OpenAI TTS
(`OPENAI_API_KEY`) -> Piper (офлайн, если стоит `piper-tts`). Другие языки начинают с edge-tts.
Принудительно: `SHORTS_TTS=voiceengine|edge|elevenlabs|openai|piper|silent`; `SHORTS_VOICEENGINE=off` убирает встроенный.
- Голос = строка атрибутов VoiceEngine: `"ж, 90"`, `"м, 7, радостно"`, `"дракон"`, `"ведущая"`, `"m2"`, `"voice=Нюра"`.
  Старые имена работают: `ru-male-1` (= `диктор`), `ru-female-1` (= `ведущая`), `en-male-1`, `en-female-1`, `*-2`;
  имена голосов edge / Piper / OpenAI уходят своим движкам. Другие движки получают ближайший стоковый голос по полу.
- Модели VoiceEngine в одном запечатанном архиве `assets/voice/` (125 МБ): не открывать, распакуется сам при первой
  озвучке или `voice-setup`. Тайминги слов: русский точный, английский оценка внутри предложения (или faster-whisper).
- Piper: `bash tools/install.sh --local` ставит piper-tts и faster-whisper. Голос по языку (ru_RU-irina-medium,
  en_US-lessac-medium) скачивается один раз в `SHORTS_MODELS` (или кэш); свой голос: `SHORTS_PIPER_MODEL=путь.onnx|имя`.
- У Piper и OpenAI нет границ слов: если стоит faster-whisper, слова берутся из распознавания нашего же звука
  (QA меряет синхрон), иначе оценка по слогам (QA пишет "estimated").
- Проверено: VoiceEngine (2.4, локально), edge-tts, Piper, faster-whisper (1.1.0). Не проверено (нет ключей): ElevenLabs,
  OpenAI TTS. `doctor` показывает это в `verification`, `doctor --deep` запускает самопроверку VoiceEngine и Piper + whisper.
Кэш по тексту и голосу: повторный рендер без синтеза. Выбор голоса запоминай в `prefs`.

## Музыка (2.4: если трек не дали, найти самому)
- **Трек пользователя или ссылка** (`music.source`: файл или URL, yt-dlp вытаскивает звук): трендовый звук, лицензированный
  трек, музыка из исходника. Выбор человека не заменяется никогда.
- **Трека нет и тишину не просили: `"music": "auto"`** (по умолчанию в `prefs`, планах, `plan`, шаблонах, мультиках `toon-*`,
  `edit` без `--music`). Скилл сам:
  1. берёт настроение из `music.mood` / `genre` / `query`, иначе угадывает по теме и эмоции плана: tense, epic, energetic,
     phonk, sad, calm, happy, tech, luxury, mystery, inspiring, gaming, romantic (русские слова тоже: «напряжённый»...);
  2. ищет на YouTube и ранжирует: «no copyright» / «free to use» в названии и бесплатные каналы выше, под голос без вокала
     (lyrics, song, feat вниз), без часовых миксов, компиляций, live и slowed, без треков последних роликов
     (`memory/music_history.json`);
  3. качает только нужный кусок через лестницу `fetch`, меряет биты, начинает на сильной доле (для эдита ищет дроп);
  4. кладёт под голос (на 10 дБ ниже голоса, подъём между фразами), пишет `music.json` и `<видео>.music.json`,
     а строку `Музыка: название - канал (ссылка)` `pack` / `deliver` сами добавляют в описания.
  Посмотреть или выбрать заранее: `python3 tools/shorts.py music-find --for plan.json [--mood tense] [--dry] [--apply]`;
  другой трек: `music-find --force` (или удалить `music.json`).
- **YouTube не отдаёт звук** (IP дата-центра, «not a bot») после всей лестницы: ролик собирается без музыки, в `music.json`
  выбранный трек и готовая команда yt-dlp для компьютера пользователя. Сказать это одной строкой с командой, остальное
  делать дальше; файл от человека: `audio.music.source` = путь. Музыку не генерировать и чужой трек не выдавать за его.
- **`"music": "none"`** (или `"off"`) только если человек сам попросил без музыки или поставит трендовый звук в приложении
  (тогда лучше `audio.export: both`, см. ниже). `SHORTS_MUSIC_AUTO=off` выключает поиск (тесты, офлайн): `auto` = без музыки.
- Права: «no copyright» в названии не гарантия. Ссылку на трек дать человеку, условия автора проверяет публикующий
  (`pack` пишет это в отчёт). Content ID может заявить трек: ролик не блокируется, но доход может уйти владельцу.
- Встроенные `assets/audio/bed.mp3` и `edit.mp3` сгенерированы кодом (`tools/make_assets.py`: 808, бочка, хлопок, хэты,
  ковбелл) и звучат искусственно: это заглушки для тестов (`--music builtin`), QA пишет `audio_honesty: warn`, `deliver`
  такой ролик не выдаёт. Сохранённый в `prefs` старый выбор `bed.mp3` команда `plan` считает «не выбрано» и ставит `auto`.
Под голосом музыка на 10 дБ ниже голоса (`music.gain_db`), между фразами поднимается до 6 дБ (`duck_db`), фейды 0.3/0.8 с.
Биты: `beats файл|URL` (librosa: темп, доли, сильные доли, энергия); для HTML-сцены `beats трек --js beats.js --main 9`
(`reference/code-video.md`).

## SFX (2.2: только реальные записи)
Синтезированные тона в ролик не попадают: колокольчики, «пиу»-райзеры, 808-удары, писк - это и есть «ИИ-слоп».
- `audio.sfx: "files"` (по умолчанию): звучит только файл `assets/audio/sfx/<имя>.wav|mp3|ogg|flac` (настоящая
  запись, источник и лицензия в `assets/audio/SOURCES.md`). Событие без файла выбрасывается и пишется в
  `manifest.json -> sfx_policy.dropped`.
- `audio.sfx: "off"`: никаких эффектов. `audio.sfx: "synth"`: черновик, только шумовые `click`, `whoosh`, `shutter`
  (QA предупреждает). Тональные `tick`, `pop`, `riser`, `hit` не синтезируются никогда.
- `audio.sfx_auto` (авто-whoosh на склейках, pop на CTA, click на кликах) по умолчанию выключен.
- Эдиты: переход к дропу делает сам трек (тишина-пауза перед дропом, удар музыки), а не добавленный звук.
- Уровень эффекта -14 дБ к миксу. Эффект нужен, только если он что-то объясняет (клик мыши в уроке, затвор камеры).
Чужие библиотеки (Mixkit, ElevenLabs) в скилл не копируем: лицензии запрещают распространение; AI-генерацию звука не используем.

## Громкость
Двухпроходный loudnorm: -14 LUFS, true peak -1.5 dBTP (QA: -14 +-1.5, пик не выше -1). Ролик понятен без звука.

## Версия без музыки (1.3)
`"audio": {"export": "both"}`: рядом с роликом `<name>.nomusic.mp4` (голос + звуки, та же громкость) и
`music_cue.json` (трек, старт, дроп, сильные доли). Загрузи `nomusic` и добавь трендовый звук в приложении:
склейки и дроп уже стоят под исходный трек. `without_music`: главный файл без музыки. Звук фона-геймплея
(`bg:`) всегда выключен.

## Согласование платных API (v3.4)
Потенциально платные HTTP-запросы TTS OpenAI/ElevenLabs и генерации обложек OpenAI/Gemini
по умолчанию заблокированы, даже при наличии API-ключей. Получить разрешение на конкретный
объём/бюджет, затем установить SHORTS_ALLOW_PAID=1 только для этого задания и сбросить после.
Флаг не является счётчиком расходов и не разрешает публикацию/закупку трафика.
Кэш озвучки и локальная сборка обложек из кадров не требуют платного запроса.
Если API заблокирован, не объявлять генерацию успешной: использовать разрешённый fallback
или сообщить точный блокер. Согласование и лимиты записать в бриф/отчёт.
