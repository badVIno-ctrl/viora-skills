# Один файл для обычного человека

Агент делает `meta DIR`, `cover DIR`, финальные `qa DIR --strict`, просмотр и `review DIR`,
потом `package DIR`. Выход: DIR/ПАКЕТ.txt (UTF-8), JSON остаётся внутренним.
Команда all тоже создаёт предварительный пакет, но не подменяет ручной просмотр и творческую проверку.
После изменений metadata, cover, QA или review пакет обновляется; после последнего запуска
агент заново проверяет его и дописывает только подтверждённые смысловые итоги.

## Что должно быть внутри
- РЕКОМЕНДУЕМОЕ НАЗВАНИЕ на отдельной строке и весь набор 5-7 названий с объяснением каждого.
- Готовые к копированию описание YouTube, закреп ровно из трёх строк, подпись TikTok.
- A/B/C: фактический текст каждой обложки, имена файлов и простые промпты «Нарисуй...»
  при отсутствии генератора. Если C собран как один затемнённый кадр, не называй его парой «до/после».
  Не выдумывай второе состояние. Первый кадр Shorts - обложка в ленте.
- Хэштеги для названия и низа описания. Не добавляй их второй раз к уже готовому названию.
- Шесть простых действий загрузки с условной, а не автоматической настройкой пометки ИИ-контента.
- Честные разделы: кодом / глазами ИИ / не проверено. QA pass не означает, что ИИ видел кадры,
  слушал звук, проверил факты или получил охваты. Кадры не равны просмотру видео целиком.
- «Через сутки и через неделю пришли мне цифры: показы, сколько досмотрели, лайки, подписки».
  Предложи скриншоты, не таблицу для заполнения.

Прочитай файл перед выдачей. Встроенный шаблон ru/en, остальные языки переводит агент сам;
названия и подписи должны оставаться на выбранном языке ролика. Не заставляй человека переводить
технический отчёт. Незакрытые проверки опиши словами, а не списком внутренних кодов.
Впиши наблюдение об обложках 150 px и результат P0/P1/P2 из wow-review.md, если они реально выполнены.
Не называй статус «готово», пока ручные и технические проверки не закончены.
Текст без таблиц, Markdown-ограждений, JSON и кода. Пакет содержит только публичные данные:
не вставляй туда ключи, токены, cookies или весь prefs. Ссылки и ники - только от пользователя.
Не открывай prefs для человека вместо пакета.

## Выдача
Приложи сам MP4, ПАКЕТ.txt, обложки и существующий .srt. В чате достаточно пары предложений
и рекомендованного названия. Укажи путь out/<имя>/ПАКЕТ.txt и предоставь скачивание файла,
а не только серверный путь. Не выкладывай видео в git.
