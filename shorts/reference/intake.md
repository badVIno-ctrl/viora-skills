# Первый запуск, настройки, напоминания

## Бренд (одним сообщением, только недостающее)
Перед каждым роликом прочитай `prefs show`, включая отвергнутые варианты. Спроси простыми словами:
1. Кто вы и что за канал или бренд: имя, о чём канал, для кого.
2. Куда хотите прийти: подписчики, продажи или просмотры.
3. Что делаем прямо сейчас: идея, ссылка, файл, тема или «придумай сам».
4. Куда выкладываем и на каком языке.
5. Ссылки и ники для закрепа и QR, если есть.
6. Голос и стиль или «выбери сам».

`intake` печатает один блок; агент убирает уже известные подпункты внутри общих вопросов.
JSON и команды человеку не показывай. Профиль бренда не равен пресету оформления.
Не спрашивай про раскладку, движки, схемы и генераторы: их выбирает агент; уточняй лишь важный выбор.
Если человек ответил «нет ссылок», сохрани пустые links и qr=false, не спрашивай заново.
«Выбери сам» - полноценный ответ: выбери настройки и сохрани brand.style_choice, voice и music.
Нишу выведи из описания канала; уточняй только если без этого нельзя выбрать тему.
Цель меняет формат и главный CTA: подписчики - серия, продажи - польза и ссылка пользователя,
просмотры - самостоятельный сильный момент. Не обещай доход или охваты.
Новую задачу выясняй каждый раз, но известные бренд, голос и ссылки повторно не спрашивай.
Пропуск brand.profile не закрывает brand.goal: это отдельные поля напоминаний.

## Сохранение бренда (делает агент)
- `prefs set 'brand.profile={"name":"Анна","topic":"домашние растения","audience":"начинающие"}'`
- `prefs set 'brand.niche=домашние растения для начинающих'`
- `prefs set 'brand.goal=подписки'`
- `prefs set 'brand.telegram=t.me/ник'` и `prefs set 'brand.offer=чем занимаетесь и что рекламируем'`: вход для рекламных баннеров (`ad-card`, `stack`). Пропуск не блокирует работу, но баннер тогда не делаем, а напоминаем.
- `prefs set 'brand.style_choice=выбери сам'` + выбранные `brand.preset`, `voice`, `music`.
Пиши вложенные поля через dotted keys, не заменяй весь brand пресетом, иначе потеряется профиль.
Задачу сохрани как source и source_brief, но не путай её с постоянной целью канала.
Повторный запуск: прочитай prefs, подстройся, спрашивай только новую задачу или изменения.
Для новой ниши прочитай reference/niche-entry.md; отказ от стиля/голоса/формата запиши через
`remember_choice("rejected", ...)` или `prefs remember rejected=...`, больше не предлагай.
Принятый заголовок: `prefs remember chosen_title=...`.

## Как сохранять
| Ответ | Команда |
|---|---|
| язык | `prefs set 'language={"chat":"ru","video":"en"}'` |
| платформы | `prefs set 'platforms=["youtube_shorts","tiktok"]'` |
| раскладка | `prefs set layout=three` (или `top_center`, `center_bottom`, `center_only`) |
| панели | `prefs set 'panels={"top":"assets/footage/my-game.mp4"}'` |
| ник | `prefs set handle=VioraStudio` |
| ссылки | `prefs set 'links={"telegram":"https://t.me/VioraStudio"}'` |
| QR | `prefs set qr=true` |
| стиль | `prefs set brand.preset=viora` |
| голос | `prefs set 'voice={"engine":"auto","voice":"ru-male-1","speed":1.05}'` |
| пропустил пункт | `prefs skip panels` (ставится значение по умолчанию + напоминание) |
| закрыл пункт | `prefs set ...` закрывает сам, или `prefs done panels` |
| сброс | `prefs reset` |

Поведение тоже запоминаем: выбранное название `remember_choice("chosen_title", ...)`, отклонённое
(стиль, голос, формат) `remember_choice("rejected", ...)`. Перед следующим роликом посмотри `prefs show`
и не предлагай отклонённое снова.

## Повторный запуск
`prefs summary` -> "Беру настройки как в прошлый раз: ... Менять?". Спрашивай только новое.

## Напоминания
В конце КАЖДОГО ответа с роликом, пока `pending` не пуст: `prefs remind` -> одна строка
"Не заполнено: ссылки для нижней панели. Дать сейчас?". Без нотаций, одной строкой.

## Значения по умолчанию
Язык ru, платформа youtube_shorts, раскладка `three` для сервисов и `center_only` для эдитов,
пресет `mono`, голос auto (2.4: встроенный VoiceEngine, `reference/voice.md`), музыка `auto` (2.4: трек пользователя,
а если его нет и тишину не просили, скилл сам находит трек на YouTube по настроению, `reference/audio.md`; встроенные
`bed.mp3`/`edit.mp3` - сгенерированные заглушки, не по умолчанию), QR включён,
если есть ссылка (кроме эдитов: в эдите ссылка плашкой `link`, выезжает в центр, без QR).

## Реклама и разработка скилла (v3.4)
Прежде вопросов определить режим по reference/advertising.md. Для обновления скилла
рекламный бриф НЕ нужен. Для реальной рекламы дополнить входы оффером/допуском,
аудиторией/ГЕО/возрастом, лицензиями, точкой перехода, аналитикой и полномочиями.
Не подставлять ссылки/ники из prefs.example.json. Три панели и QR не обязательны:
выбирать композицию под смысл, не добавлять геймплей и Telegram автоматически.
