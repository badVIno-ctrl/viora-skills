# Миграция 1.6.2 / traffic v3.4.1

Старые campaign.json advertising-1 совместимы: отсутствующее qa.*.applicability
означает applicable. Для static_ad у motion_audio/subtitles теперь использовать
not_applicable + passed=false + evidence с конкретной причиной. Для видео и других
пунктов такое исключение запрещено. Права, согласие и допуск не обходятся через N/A.
Новая учебная цель training_comprehension требует training_product=true и
monetization=training. Это цель обучения/проверки понимания, не подтверждённая продажа.
Учебный launch запрещён независимо от заполнения доказательств. Внутренний CTA без URL
допустим для draft; коммерческий launch по-прежнему требует подтверждённый путь.
CLI ad-check дополнительно сохраняет снимок стадии; ad-qa.json остаётся последним.
Повтор стадии заменяет её файл: для истории нескольких версий сохранять отдельные копии.
Видеорендер, plan schema и release-контракт не изменены этой поправкой.
