# Исследование: обложки Shorts/Reels/TikTok (для скилла shorts-2.0)
Метки надёжности: **[оф]** документация YouTube; **[дан]** исследование с данными (часто вендорское, корреляция ≠ причинность); **[пр]** практика/мнение; **[вывод]** мой вывод/эвристика (не источник).

## 0. Главное (10 пунктов)
1. Обложка Shorts = кадр ролика ИЛИ загруженная 9:16 картинка (только Studio на компьютере, верифицированный аккаунт) — https://support.google.com/youtube/answer/72431?co=GENIE.Platform%3DDesktop&hl=en
2. В свайп-ленте Shorts видео стартует сразу, обложка там почти не работает; она решает в поиске, на главной, подписках, в сетке канала — https://www.searchenginejournal.com/youtube-rolls-out-new-shorts-thumbnail-editing-features/526162/ , https://shortgenius.com/blog/youtube-shorts-thumbnail. Значит ПЕРВЫЙ кадр ролика тоже должен быть «обложкой» [вывод].
3. Один фокус: крупное лицо/герой + 2–4 слова + контрастный фон. Лицо ≥30% высоты кадра, текст ≥160 px высотой букв.
4. Текст рендерить Pillow (точный, кириллица), не нейросетью: у claude-youtube-editor «мелкий текст в AI-рендере коверкается» — https://github.com/hassancs91/claude-youtube-editor
5. Три варианта должны отличаться кадром (разные сцены/тайм-коды), масштабом кропа, текстом и цветовой схемой; проверять автоматически (pHash).
6. Безопасная зона: ключевое в y≈290–1340 px и x≤920 (консервативно) — см. §2.
7. Серый/тусклый кадр, мелкий текст, текст на лице, letterbox 16:9 внутри 9:16 — главные признаки «дешёвой» обложки.
8. Для интервью — отдельная 9:16-композиция (не кроп 16:9), лицо вверх, слова в среднюю полосу.
9. Для эдитов специфичных источников нет — применять постер-логику (герой крупно + свечение + цитата) как **[вывод]**.
10. VPN-реклама в РФ с 01.09.2025 запрещена законом (штрафы) — стоит предупредить пользователя: https://ria.ru/20250901/shtraf-2038724982.html

## 1. Что реально в репозиториях (клонированы в /tmp/w/research/repos, прочитаны SKILL.md/код)
**miqdadbadjuber/anti-slop** — правила для UI-кода, не для картинок; полезен принципом. Файлы: antislop.md, skills/antislop-ui, antislop-human (+contrast-check.py).
- Принцип «purpose test»: каждый эффект (градиент, glow, тень) должен служить иерархии; «потому что так делает ИИ» — красный флаг. Не запрещает приёмы, запрещает «технику без цели» (antislop.md ~стр.117–154).
- Признаки slop (таблица «Visual & Color», antislop.md ~стр.178–193): сине-фиолетовый градиент; glow везде; «5–7 цветов в палитре без системы»; акцентный цвет на всём; стек трендов (glass+mesh+glow+grid); стерильный «безопасный» дефолт без идентичности; серые заглушки вместо реального продукта.
- Контраст: AA ≥4.5:1 (обычный текст), ≥3:1 (крупный). «Тестировать худшую точку под текстом на картинке/градиенте, добавлять scrim или сплошную подложку»; «белый текст на градиенте, местами светлом — запрещено». Скрипт: `python3 contrast-check.py "#FFFFFF" "#777777"`.
- Применимо к обложке: ≤3 цветов (фон-тёмный/светлый + 1 акцент + белый/чёрный текст); каждый эффект — с причиной; не выдумывать логотипы/лица (R-23 «Assumed Logo & Profile Photos»).
**hassancs91/claude-youtube-editor** — самое релевантное (.claude/skills/thumbnail, references/style-elements.md, tools/thumb_scrim.py, gen_thumbnail.py).
- Всегда: сильный контраст, насыщенный цвет, чёткая иерархия, позитивное лицо, «чёткий неперегруженный текст». Текстовый бюджет по умолчанию **минимальный**: ОДИН хук-элемент (single-hook), «полный набор (заголовок+стикер+чекстрип+тег) пробовали и отвергли как слишком много текста».
- Иерархия текста «tiered»: контекст-строка — белая, средняя; «power line» — в ~2× крупнее, акцентный цвет, hard drop shadow; «цветовой контраст = иерархия». Стикер — максимум 2 слова, наклонный жёлтый, чёрные буквы, красное подчёркивание + короткая стрелка на объект. Акценты: зелёный/жёлтый/красный/голубой.
- Авторский кейс: «плоский/низкоконтрастный/без иерархии» против «яркий/контрастный/иерархичный» — второй выиграл **~4.4× по просмотрам** (один кейс автора, не статистика).
- thumb_scrim.py (готовые числа): затемнение фона под заголовком strength **0.55**, вертикальный fade до 0 на **40% высоты**, по горизонтали полная сила до **55%** ширины, спад до **75%**, защита насыщенных букв по оттенку. JPG ≤2 МБ.
- Процесс: A/B/C-концепты, у каждого сохранён prompt+seed, сравнение «contact sheet» с подписями, verify-checklist (орфография, читаемость, иерархия, лишние буквы, руки, честность). Лицо — из референса, не «выдумывать».
**mischacoster/image-skill** — генератор GPT-Image/Gemini; полезно `references/concept-mode.md`: «4 концепта, которые на деле 2 идеи» — лечится реально разными промптами; оси различия: стиль / композиция (close-up, wide, dynamic) / интерпретация / настроение / палитра (high-contrast, mono, two-tone, single accent); выбирать **две оси для максимального разброса**; если стиль задан — варьировать композицию и палитру. Текст/идентичность — GPT, атмосфера — Gemini. (Для нас: оси переносятся на 3 варианта, генерация не нужна.)
**anthropics/skills** — canvas-design: «90% визуал, 10% текст», текст «минимальный, полностью внутри холста»; второй проход — **улучшить чёткость/пробелы/палитру/типографику, не добавлять графику; проверить, что ничего не перекрывается и не вылезает**. frontend-design: «опинионейтед, а не дефолтные» палитра/шрифт; признаки AI-дефолта: кремовый фон + serif + терракота; «чёрный + кислотно-зелёный акцент»; одинаковые карточки с мягкой серой тенью; акцент на одном слове заголовка цветом («tell»). theme-factory: 10 пресетов (4 hex + шрифты DejaVu) — для обложек бесполезны. algorithmic-art (p5.js) — нерелевантен.
Вывод по репо: готового кода обложек для Shorts в них нет; брать принципы (одна иерархия, ≤3 цвета, scrim, проверка перекрытий, разброс осей вариантов) + их числа scrim.

## 2. Где показывается обложка Shorts и безопасные зоны
- Размер загружаемой: рекомендуемо 2160×3840, мин. высота 640, 9:16; десктоп ≤50 МБ (моб. ≤2 МБ), JPG/PNG — [оф] support.google.com/youtube/answer/72431 (Desktop).
- Выбор кадра/текст/фильтры на обложку — в приложении после/до загрузки (текст, эмодзи, фильтры) — https://www.searchenginejournal.com/youtube-rolls-out-new-shorts-thumbnail-editing-features/526162/ [дан/пр]. Один источник утверждает «своей картинки нет» (monty.fast) — **устарело/неверно** относительно справки YouTube; верить справке.
- Не показывается в главной свайп-ленте Shorts (SEJ, ссылка выше).
- Формат 4:5/3:4: для Reels — лента 4:5, сетка 3:4 (https://monty.fast/ru/blog/oblozhka-dlya-rilsa/); для Shorts подтверждения нет **(не подтверждено)**. Страховка: ключевое в центральном квадрате 1080×1080 (y≈420–1500) — monty.fast.
- Интерфейс Shorts (оценки, официальных пикселей YouTube не публикует — https://hypenest.ai/templates/youtube-shorts-safe-zone): сверху ≈120 px (поиск/меню), снизу ≈300–360 (канал, подписка, название, звук), справа ≈96 (лайк/коммент/share), слева ≈48. Консервативно (https://framenotion.com/blog/safe-zone-guidelines-for-vertical-video-ads): Shorts сверху ~230, снизу 384–576, справа ~162; общий безопасный прямоугольник **y 288–1344, x ≤918**, слева 86–108.
- Рабочая зона текста: 20–60% высоты (y≈384–1150) — https://anatomystudy.ru/oblozhka-shorts-reels ; нижние 25–30% не использовать (Conbersa/wildandfree).
- Размер превью в ленте/поиске ≈200×350 px (https://www.conbersa.ai/learn/podcast-clip-thumbnail-strategy) → тест читаемости: уменьшить до 108×192 и 200×350. MrBeast-команда: «смотреть в реальном малом размере, не увеличенным» — https://www.socialmediatoday.com/news/youtube-shares-insights-mrbeasts-team-creates-compelling-thumbnail/709817/

## 3. Что кликается: правила и данные (с оговорками)
- **MrBeast/Chucky** [оф-интервью]: просто, не перегружать, понятно сразу, связано с видео, тест ~50 концептов/видео, лицо во всех с 2019 (https://www.socialmediatoday.com/news/youtube-shares-insights-mrbeasts-team-creates-compelling-thumbnail/709817/ ; видео https://www.youtube.com/watch?v=HP-rqigfw2s). Закрытый рот победил открытый в тестах на 30 видео по **времени просмотра** (не CTR) — https://www.theverge.com/2023/9/6/23861576/youtube-face-mrbeast-open-closed-mouth-a-b-testing-thumbnail → «кричащее лицо» не догма; естественный, «пойманный в действии» кадр часто выигрывает.
- Анализ ~3000 обложек MrBeast [дан, качественно, без процентов]: выигрывали размытый фон, сильный контраст фор/бэк, тёмный фон + яркий передний план, действие > статика, крупный зум, красный/зелёный/жёлтый; простой контраст > «драматичный» фильтр — https://www.linkedin.com/pulse/i-studied-3000-mrbeast-thumbnails-heres-what-learned-josiah-hritsko-hkyae
- 1000 обложек [дан, вендор, корреляция]: лицо 6.8% CTR vs без лица 4.1%; экстремальная эмоция 7.9 / умеренная 5.6 / нейтральная 4.2; фон сплошной тёмный 6.9 / сплошной яркий 6.1 / фото-сцена 4.4; текст 1–5 слов 7.2% vs 11+ слов 4.1% vs без текста 4.3% — https://ctrpilot.com/blog/youtube-thumbnail-study-1000-videos
- Контр-данные: 300K вирусных видео — лица в целом не дают заметного преимущества, зависит от ниши (финансы +, бизнес −) — https://www.searchenginejournal.com/do-faces-help-youtube-thumbnails-heres-what-the-data-says/563944/ ; TubeAnalytics: эмоциональное лицо +18–32% CTR, текст 3–5 слов +11–22% в поиске, но −4% в browse; насыщенный фон +8–14% — https://www.tubeanalytics.net/resources/research/thumbnail-ctr-patterns-study-2026 . Вывод: правила — гипотезы, поэтому нужны 3 реально разных варианта и A/B (YouTube умеет до 3 вариантов; победа ≥20% отн. прироста и ≥1000 показов на вариант — shortgenius.com).
- Размеры: лицо ≥15% площади (Cre8Virals, слабая), ≥25% (anatomystudy), 40–60% (Conbersa), высота лица ≥1/3 кадра, лучше 1/2 (https://thumbnailbench.com/resources/podcast-thumbnails). Для 9:16 берём: **лицо 30–45% высоты кадра (580–860 px)**.
- Текст: 2–4 слова (shortgenius), 3 макс. (Cre8Virals/thumbnailbench), «≤5» (anatomystudy), высота букв ≥15% ширины ≈160 px (anatomystudy), подложка/обводка, шрифт bold/extra-bold без засечек. Цвета текста: белый/жёлтый с толстой чёрной обводкой (Conbersa); пары жёлтый/чёрный, циан/тёмно-красный (Cre8Virals). Красный/жёлтый/белый в >65% обложек MrBeast (weenytools, вендорская статистика; пропорция ~60/30/10).
- Обводка/выделение субъекта: 2–5 px на 1280×720 (Cre8Virals, слабый источник) → на 1080×1920 **6–10 px**. Насыщенность: субъект ×1.3–1.5, фон без изменений (Cre8Virals «80/20» — не проверено, использовать умеренно).
- Официально YouTube: правило третей, простой дизайн, изображение как можно крупнее, 90% лучших видео с кастомной обложкой, фоткать запасные кадры — https://support.google.com/youtube/answer/12340300?hl=en

## 4. По жанрам
**Эдит из фильма** (источников «как делают обложки эдитов» не найдено — **[вывод]**, опираясь на постер-логику + MrBeast): кадр героя из «хук-момента» (где он говорит ту самую фразу), крупно, взгляд в камеру/профиль с эмоцией; кинограда (тёмный фон, 1 акцент: тёплый оранж/красный/циан), свечение-контур вокруг фигуры 8–14 px blur в цвете акцента; текст — цитата героя 2–4 слова в верхней трети или одно слово («ЭДИТ» — мелко, ≤40% размера цитаты, или не нужно). Без лого каналов, без рамок, без 5 эффектов. Хук: эдит начинается с цитаты героя → эта же цитата = текст обложки и первый кадр ролика (рекомендация пользователя: tjmbz1k9wsU, wwMeX-qDfoA).
**Интервью/подкаст-клип**: лицо одного человека крупно (не два лица равного размера), текст — число/вопрос/заявление 3 слова, «лицо вверх, слова в среднюю полосу, объект вниз/мелко», для Shorts — отдельная 9:16 композиция, не кроп 16:9 — https://thumbnailbench.com/resources/podcast-thumbnails ; кадр: лицо в выражении (не моргание/полуслово), один человек плотным планом, не вид «two-shot», лицо вне зоны названия/кнопок — https://www.valoraearc.com/blog/podcast-clip-thumbnail-youtube-shorts ; хук клипа «найден, не придуман»: самая сильная фраза спикера (число, поворот, ответ) — https://www.usekeymo.com/guides/hooks-for-youtube-shorts . Число/деньги в тексте («$100 000?») = «number-forward» [пр]. На приложенном скриншоте (на глаз): 16:9 окно занимает ~50% высоты, лицо ~8–10% высоты, блюр-полосы сверху/снизу — это ровно «полу-шортс»; нужен настоящий вертикальный кроп с трекингом лица.
**Нарезка шуток**: кадр реакции (смех/шок) крупно, 1–3 слова — тема шутки/«ржака»-триггер, яркий/сплошной фон (в данных: сплошной фон > фото-сцена) **[вывод по ctrpilot]**; не «скрин с субтитрами».
**VPN/реклама**: обложка — НЕ реклама; QR на обложке бессмыслен (в миниатюре не сканируется) **[вывод]**; рекламная плашка — внутри видео, в центр/нижнюю часть ядра, не у правого края, не под UI (framenotion). ## 5. Алгоритм выбора кадра (скоринг кандидатов)
Кандидаты: окно хука (первые 1–2 с клипа — Conbersa) + пики речи; сэмпл каждые 0.25 с, 2–4 финалиста (Conbersa).
Признаки (вес): 
1. Лицо найдено (YuNet/Haar), одно доминирующее: **доля высоты лица в кадре 0.18–0.45 после 9:16-кропа** (+30); меньше 0.12 — отбраковать.
2. Резкость на ROI лица: variance of Laplacian (PyImageSearch, порог 100 — только старт, калибровать по клипу; https://pyimagesearch.com/2015/09/07/blur-detection-with-opencv/); отбраковать <60% от медианы клипа (+20). Сравнить с соседними кадрами, чтобы убрать смаз движения.
3. Глаза открыты и ≈ в камеру (2 глаза найдены каскадом/лэндмарками, симметрия по носу) (+15); моргание/«полуоткрыт» — отбраковать.
4. Эмоция/рот: ярко выраженная — широко открытый рот (удивление/смех) ИЛИ чётко закрытая улыбка; **отбраковать «середину слова»** (рот полуоткрыт, асимметрия) — Conbersa/Valorae (+15). MAR (mouth aspect ratio, MediaPipe FaceMesh) >0.5 = открыт, <0.1 = закрыт, 0.15–0.4 — подозрительная «полуфонема» [вывод].
5. Экспозиция лица: средняя яркость лица 90–180 (из 255), клиппинг белого/чёрного <3% пикселей, не серый кадр: std яркости кадра >45 (+10).
6. Цвет: «насыщенность» (Hasler–Süsstrunk colorfulness) или средняя S в HSV >0.25; серый/бежевый кадр — штраф (+5).
7. Композиция: глаза на линии ~1/3 сверху (y≈0.30–0.42 H), место под текст (пустая зона ≥18% высоты вне лица) (+5).
Штрафы: переходы/затемнения/титры, чужие субтитры, водяные знаки, пересвет, два лица равного размера.
Для эдитов без лица: кадр с максимальным локальным контрастом + цветом, «герой» по saliency (cv2.saliency), не пустой пейзаж.

## 6. Три варианта: чем РЕАЛЬНО отличаются
Жёсткие критерии (проверять кодом): тайм-коды ≥3 с друг от друга ИЛИ разные сцены; масштаб кропа различается ≥1.4×; тексты разные по смыслу (не синонимы); оттенок акцента разнесён ≥90° по HSV-кругу; **pHash(64) Хэмминг-дистанция ≥12 между любой парой**, иначе заменить кадр/кроп.
- **A «Лицо-крупно»**: лучший кадр, лицо 40–45% высоты, тёмный фон, акцент жёлтый #FFD400, текст 2–3 слова-заявление, верхняя треть.
- **B «Контекст/интрига»**: другой кадр (шире: спикер+объект/второй человек/предмет), лицо 25–30%, акцент красный #FF2D2D или циан #00D1FF, текст — число/вопрос («$100 000?»), средняя полоса, стрелка/кружок на ключевой объект.
- **C «Постер»**: третий кадр/момент, максимальный крупный план (50%+ или тайт-кроп глаз), другая обработка: ч/б или дуотон + один акцент, свечение-контур, текст-цитата 1–3 слова ИЛИ 1 слово.
Оси из image-skill: композиция + палитра + текст; стиль (фото/кинограда) держать общим → бренд-узнаваемость (consistency: тот же шрифт, обводка, положение логотипа — https://anatomystudy.ru/oblozhka-shorts-reels, пр.7).
Contact sheet: три обложки в ряд, на уменьшении 108×192; визуально должны быть различимы «с первого взгляда».

## 7. Чего НЕ делать (признаки «шлака»)
- Мелкий текст (высота заглавных <160 px при ширине 1080), >5 слов, >2 шрифтов, 5–7 цветов (anti-slop «Too many colors»).
- Текст на лице/глазах/рте; текст в нижних 25–30% и у правого края; текст без подложки/обводки на «шумном» фоне.
- Серый/плоский/низкоконтрастный кадр; кадр «мид-слово»/моргание; нечёткий смазанный кадр; апскейл >2×.
- Все 3 варианта из одного кадра с разным текстом; одинаковый кроп; градиент-заглушка вместо кадра; фиолетово-синий градиент «потому что ИИ» (anti-slop); glow/тени на всём.
- Letterbox: 16:9 видео в центре 9:16 с блюр-полосами (чистый 16:9 в 9:16 занимает лишь ~32% высоты, остальное — пустота/блюр).
- Субтитры исходника в обложке, водяные знаки, логотипы источника, QR/ссылки на обложке, эмодзи >1–2 (social-pro.com.ua).
- Текст «рисовать» генеративной моделью (коверкает кириллицу) — только Pillow.
- Клик-бейт, не соответствующий видео: YouTube-команда требует «связь с видео» (SocialMediaToday).
- Выбор шрифта: Anton НЕ содержит кириллицу (subsets latin, vietnamese — github.com/google/fonts ofl/anton/METADATA.pb); Oswald, Montserrat (Black/ExtraBold), Russo One — кириллица есть (METADATA.pb). В песочнице системно только DejaVu → шрифт класть в репозиторий скилла (OFL).

## 8. Технический рецепт (Pillow/OpenCV, 1080×1920) — псевдокод
```python
W,H=1080,1920; SAFE=(60,290,918,1344)            # x0,y0,x1,y1 для ключевого
def smooth_s(x,k): return x+k*(x*x*(3-2*x)-x)      # S-кривая, k=0.45..0.6

def build(frame, face, text, accent, mode):          # face=(x,y,w,h)
    # 1) кроп 9:16 вокруг лица: высота лица -> target*H, центр лица на y=0.38H
    tgt={'A':.42,'B':.28,'C':.52}[mode]; s=tgt*H/face.h; assert s<=2.0   # >2x = мыло, взять другой кадр
    img=crop_resize(frame, scale=s, face_center=(W/2, .38*H), out=(W,H), resample=LANCZOS)
    # 2) тон: S-кривая по V, +контраст, насыщенность
    hsv=rgb2hsv(img); hsv.V=smooth_s(hsv.V,.5); hsv.S=clip(hsv.S*1.15,0,1)
    # 3) маска персонажа (rembg/MediaPipe selfie seg); нет маски -> эллипс лица×2.2
    m=person_mask(img)
    bg=img*(1-m); subj=img*m
    bg=blur(bg,sigma=6)*0.6 if mode!='C' else gray(bg)*0.5     # затемнить/приглушить фон
    subj=saturate(subj,1.3); subj=unsharp(subj,r=1.2,amt=0.6)
    # 4) свечение-контур: dilate(m,8px)-m -> blur(14) -> цвет accent, screen-blend alpha .85
    rim=gauss(dilate(m,8)-m,14)*color(accent); out=screen(compose(bg,subj),rim*.85)
    # 5) виньетка: радиальная, край темнее на 35% (смещена к центру лица)
    out*=1-.35*radial(dist_from(W/2,.45*H)/(0.75*H))**2
    # 6) scrim под текст: чёрный 0->0.55 по y от 0.15H до 0.55H (thumb_scrim: .55, fade 40%H)
    # 7) текст: Oswald-Bold/Montserrat-ExtraBold, ВЕРХНИЙ РЕГИСТР, ≤3 строк, ≤4 слов
    size=int(.115*H)                                      # ≈220px, капс ≈160px+
    while text_w(lines,size)>0.84*W or lines_h>.30*H: size*=.94
    stroke=max(10,int(.06*size)); y=.20*H                  # зона 20–55% H
    draw_text(lines,font,size,fill=WHITE|YELLOW,stroke_width=stroke,stroke_fill=BLACK,
              shadow=(0,6,blur=8,alpha=.6),fit_in=SAFE)
    assert not intersects(text_bbox, face_eyes_mouth_bbox(pad=20))   # текст не на лице
    # 8) акцентная строка: вторая строка в accent, ×1.25 размер (tiered); стрелка/кружок 8–10px, цвет accent
    # 9) финальное резкое: unsharp r=0.8 amt=.4; экспорт JPEG q=92, ≤2MB (PNG для превью)
    return out

def qa(path, face_box, text_bbox):
    im=open(path); assert im.size==(1080,1920)
    t=im.resize((108,192)); assert contrast(text_region(t))>=4.5      # WCAG, худшая точка под текстом
    assert face_h_ratio in (.25,.55) and sharp(face)>=thr and not inside(UI_ZONES,text_bbox)
    assert min(phash_dist(a,b) for a,b in pairs(variants))>=12
```
Параметры сводкой: шрифт 11.5% высоты (≈220 px), обводка ≈6% кегля (≥10 px), обводка субъекта 6–10 px + blur 14, виньетка 0.35, S-кривая k≈0.5, насыщенность фон ×1.15 / субъект ×1.3, scrim 0.55, акценты #FFD400 / #FF2D2D / #00D1FF, текст белый/жёлтый + чёрная обводка.
