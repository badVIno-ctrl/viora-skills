# Шрифты

Все из Google Fonts (github.com/google/fonts), лицензия SIL Open Font License 1.1 (файлы `OFL-*.txt`), встраивание
в видео и картинки разрешено. Вариативные шрифты зафиксированы в статические начертания (fontTools instancer),
семейству дано имя с начертанием, чтобы libass находил его однозначно.

| Файл | Семейство | Где используется |
|---|---|---|
| Montserrat-ExtraBold/SemiBold | Montserrat | заголовки и субтитры: mono, viora |
| Jost-Light/Medium | Jost | тонкий широкий логотип и текст: viora, mono |
| Manrope-SemiBold/Bold | Manrope | текст: editorial, punch |
| Oswald-Bold | Oswald | узкий капс: punch |
| JetBrainsMono-Bold/Medium | JetBrains Mono | terminal (моно-шрифт осознанно, причина в пресете) |
| PTSerif-Bold | PT Serif | заголовки editorial |
| Unbounded-Black | Unbounded (вариативный, зафиксирован wght=900) | v2.2: крупные широкие заголовки (hook, обложки), как «крупный шрифт» в референсе VOuZxWAeXgs |
| GreatVibes-Regular | Great Vibes | v2.2: рукописное акцентное слово в заголовке (`*слово*` в hook / обложке), кириллица есть |
