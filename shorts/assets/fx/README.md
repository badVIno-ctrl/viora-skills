# assets/fx: готовые эффекты для код-видео (2.4)

Код-видео: сцену пишет модель (HTML / canvas / p5.js / Three.js), движок шортсов пишет её покадрово в MP4
через `window.seek(t)` (см. reference/code-video.md). Здесь лежат эффекты, которые можно брать без интернета.

| эффект | лицензия | что даёт | как взять |
|---|---|---|---|
| p5.brush 2.2.4 | MIT (Alejandro Campos Uribe) | живые мазки: уголь, карандаш, маркер, штриховка, заливка акварелью | `python3 tools/shorts.py fx-get p5.brush --to ПАПКА_СЦЕНЫ` |
| thinking-orbs 0.3.2 | MIT (Jakub Antalik) | 9 "думающих" орбов из точек на 2D canvas | `python3 tools/shorts.py fx-get thinking-orbs --to ПАПКА_СЦЕНЫ` |

Правила:

- копия ложится в `ПАПКА_СЦЕНЫ/vendor/<имя>/` вместе с LICENSE и SOURCE.md; лицензию не удалять;
- любой другой эффект с GitHub или npm: `fx-get github.com/OWNER/REPO` или `fx-get npm:ИМЯ@ВЕРСИЯ`;
  репозиторий без файла лицензии не копируется (код без лицензии нельзя вставлять в ролик);
- сцена с `type="module"` или importmap открывается через локальный сервер из своей папки, поэтому
  vendor/ должен лежать внутри папки сцены;
- кредит эффекта в описании не обязателен по MIT, но приятен автору: "Effect: p5.brush (MIT)".

Пример использования обоих эффектов: templates/code-video/scene.html.
