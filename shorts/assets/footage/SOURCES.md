# Видео для панелей

Своих файлов здесь больше нет: верхнюю панель рисует код (`tools/shortskit/panels.py`, CC0), в цветах бренда.

| Петля | Что | Когда (выбор `loop:auto` по словам темы) |
|---|---|---|
| `loop:race` | процедурный забег: три полосы, обгоны, трибуны и асфальт едут | скорость, сравнение, турнир, "против" |
| `loop:spin` | ряд плоско затенённых 3D-фигур (кубы, октаэдры) вращается над полосатым полом | 3D, CAD, дизайн, продукт, html-демо |
| `loop:code` | дождь кода: вся сетка заполнена, колонки падают с разной скоростью | код, ИИ, сайты, сервисы |
| `loop:runner` | вид сбоку, большой герой (70% панели) бежит и прыгает через ящики, параллакс города | игры, фильмы, эдиты, по умолчанию |

Правила (их же проверяет QA на готовом ролике): за секунду меняется не меньше 30% пикселей панели, нет тёмной пустоты
больше 25% панели. Старая петля 1.0.0 (`own-game-loop.mp4`) давала 14% и 52% тёмной пустоты: удалена.

Лучше всего в верхнюю панель ставить СВОЙ геймплей или записи проектов пользователя:
`prefs set panels='{"top": "путь/к/файлу.mp4"}'` (QA проверит его теми же правилами).

## Библиотека фона (1.3): геймплей для баннера и сплита

`library.json` описывает куски чужого геймплея для `layout.top.source: "bg:<id>"` и `layout.split[].b`
(sludge-формат, исследование 17). Видео в скилле не лежит: `bg fetch` кладёт кусок в `SHORTS_CACHE/bg/<id>.mp4`
(без звука, 30 fps, до 1080p) и пишет рядом `<id>.json` (подпись автора, замер движения, выбранное окно кадра).

| id | Что | Проверен |
|---|---|---|
| `gta_ramp` | GTA 5 мега-рампа (ZtLrNBdXT7M, Dope Gameplays): жёлтая машина на красно-белой рампе над морем | да: записан из браузера, баннер и сплит прошли QA |
| `gta_ramp_2` | GTA 5 рампа, второй ролик (5rsd34XKKkM) | нет: проверь контактный лист |
| `minecraft_parkour` | Minecraft паркур (M2j1SPMQwtI) | нет |
| `minecraft_parkour_2` | Minecraft паркур, второй (c3Db9IMwGNM) | нет |

Команды:
- `python3 tools/shorts.py bg list`: библиотека, что уже скачано, замер движения.
- `python3 tools/shorts.py bg fetch gta_ramp [--force]`: скачать кусок (yt-dlp; если YouTube пишет "Sign in to confirm
  you're not a bot", кусок сам записывается в общем браузере, в реальном времени).
- `python3 tools/shorts.py bg add <id> FILE --credit "Gameplay: канал (YouTube, ID)"`: свой файл или кусок, полученный
  другим путём. Новый id тоже можно.

Правила (из исследования 17, держит код): звук фона выключен; кусок из середины источника, без интро и меню;
кусок короче ролика = предупреждение (петля заметна); окно с движением в каждой секунде выбирает `bglib.frame_window`;
подпись автора идёт в `manifest.author_layer.credits` и в описание ("Фон: ..."). Поверх чужого фона нужен свой
слой (голос, тезисы), иначе QA `author_layer`. Не для эдитов, уроков, грустных монологов и детской аудитории.
Лучший фон: свой геймплей пользователя (`bg add my_game run.mp4 --credit "свой геймплей"`).
