# Звук: источники и лицензии

2.2: в готовом ролике звучат только реальные записи. Синтезированных тонов (колокольчики, райзеры, 808-удары,
«пиу», писк) нет. Сгенерированная кодом музыка ниже - заглушка для черновиков и тестов, не значение по умолчанию.

| Файл | Источник | Лицензия | Статус |
|---|---|---|---|
| `edit.mp3` + `edit.json` | сгенерирован кодом `tools/make_assets.py::music_edit` (140 BPM, тихое вступление 4 такта, пауза в долю, дроп на 6.857 с: 808, бочка, хлопок, хэты, ковбелл; сетка долей в json) | CC0, свой | заглушка: только `--music builtin`; `deliver` не пропускает |
| `bed.mp3` | сгенерирован кодом `tools/make_assets.py` (112 BPM, бочка, хэт, бас, пэд) | CC0, свой | заглушка для тестов и черновиков; `deliver` не пропускает |
| `sfx/<имя>.wav\|mp3\|ogg\|flac` | реальные записи (Foley, свои записи, CC0 с проверенной лицензией) | указать здесь построчно | единственный источник SFX при `audio.sfx: files` (по умолчанию) |

Синтез в `engine/audio.py::synth_sfx` оставлен только для черновиков (`audio.sfx: synth`) и только шумовой:
`click`, `whoosh`, `shutter`. Тональные `tick`, `pop`, `riser`, `hit` не синтезируются никогда: без файла событие
выбрасывается и пишется в `manifest.json -> sfx_policy.dropped`.

Свои файлы SFX кладите в `assets/audio/sfx/<имя>.wav` и записывайте источник и лицензию сюда (одна строка на файл).
Не копируем: Mixkit (запрет распространения в составе инструментов), ElevenLabs-сгенерированные клипы чужих аккаунтов,
AI-генерацию звука, треки без проверенной лицензии.
