## Что это

Viora Aegis — это **один пакет**, который превращает любого кодового ИИ-агента в дисциплинированного
security-инженера. Не «список советов», а рабочая система: методология, движок проверок,
справочники и адаптеры под каждый агент.

Собран из четырёх открытых наборов скиллов (OWASP-ревью, hardening, DevSecOps-набор и
исследовательские скиллы Trail of Bits), переработанных в одну согласованную логику без дублей и
противоречий.

**Ключевая идея:** совпадение регулярки — это *зацепка*, а не находка. Агент обязан проследить путь
«недоверенный вход → достижимый sink → реальное последствие», прежде чем что-то заявлять. Это
убирает главную боль ИИ-аудитов: поток красивых, но ложных срабатываний.

## Быстрый старт

```bash
# 1. распаковать рядом с проектом
unzip viora-aegis-v1.0.0.zip

# 2. установить в проект (агенты определяются автоматически)
bash viora-aegis/install.sh --target /путь/к/проекту

# 3. проверить
cd /путь/к/проекту
python3 .viora/skills/viora-aegis/scripts/viora.py doctor --path .
```

Windows (PowerShell):

```powershell
powershell -ExecutionPolicy Bypass -File viora-aegis\install.ps1 -Target C:\path\to\project
```

Дальше просто скажите агенту:

> «Прогони Viora Aegis по этому проекту»
> «Проверь этот PR перед мержем»
> «Захардени загрузку файлов»

## Флаги установщика

| Флаг | Что делает |
|---|---|
| `--target <dir>` | Куда ставить (по умолчанию — текущая папка) |
| `--all` | Настроить все 14 агентов сразу |
| `--agent <name>` | Только конкретный агент (можно повторять) |
| `--global` | Поставить ещё и глобально: `~/.claude/skills`, `~/.viora/skills` |
| `--dry-run` | Показать, что будет сделано, ничего не меняя |
| `--uninstall` | Убрать пакет и все указатели |

Без флагов установщик сам смотрит, что есть в проекте (`.claude/`, `AGENTS.md`, `.cursor/`,
`.antigravity/` …), и настраивает только найденное. Повторный запуск не дублирует блоки —
указатель всегда один, между маркерами `<!-- VIORA-AEGIS:START/END -->`.

## Как агент этим пользуется

Агент выбирает режим и объявляет его вслух. Восемь режимов:

| Режим | Когда включается | Что делает |
|---|---|---|
| **GUARD** | Пишет новый код | Безопасные шаблоны сразу, без переписывания потом |
| **REVIEW** | PR, коммит, диф | Проверяет только изменённое, даёт вердикт по каждой зацепке |
| **AUDIT** | «Проверь проект» | Полный проход: карта входов, сканы, отчёт `SECURITY_REPORT.md` |
| **HARDEN** | «Сделай безопаснее» | Чинит класс проблем, а не одну строку |
| **FIX** | Конкретная уязвимость | Минимальный патч + шаг проверки, что дыра закрыта |
| **TRIAGE** | Отчёт сканера / багбаунти | Отсев ложных: CONFIRMED / LIKELY / DEFENCE-IN-DEPTH / FALSE POSITIVE / UNDETERMINED |
| **DESIGN** | Новая фича | Мини-модель угроз STRIDE до написания кода |
| **AGENT-SEC** | LLM, RAG, MCP, инструменты | Prompt injection, утечка данных, права инструментов |

Поверх режимов — **Ten Laws** (десять запретов, которые агент не нарушает: не ослаблять защиту ради
зелёного билда, не трогать auth/CORS/крипту/платежи без спроса, не выдумывать находки, всегда
говорить, что НЕ проверено, и т. д.).

## CLI

Питон нужен только для сканера. Без него скилл работает в grep-режиме — регулярки лежат обычным
JSON, методология не меняется.

```bash
V=.viora/skills/viora-aegis/scripts/viora.py

python3 $V doctor  --path .                                   # стек, тулинг, точки входа
python3 $V scan    --path .                                   # полный скан
python3 $V scan    --path . --diff origin/main                # только изменённые строки
python3 $V scan    --path . --staged --only SECRET --fail-on low --quiet   # гейт для pre-commit
python3 $V scan    --path . --format sarif --out viora.sarif  # для GitHub Security
python3 $V deps    --path . --online                          # цепочка поставок
python3 $V headers https://ваш-сайт                           # заголовки, куки, CORS вживую
python3 $V baseline --path .                                  # заморозить текущий долг
python3 $V report  --in .viora --out SECURITY_REPORT.md       # отчёт для людей
python3 $V init --hook --ci github                            # хук + workflow
```

**Коды возврата:** `0` чисто · `1` есть находки на уровне гейта или выше · `2` ошибка запуска.

**Полезные флаги:** `--only INJ,SECRET` · `--severity high` · `--fail-on none|low|high|critical` ·
`--no-baseline` · `--json файл` · `--out файл`.

**Подавить ложное срабатывание** — комментарием в коде, обязательно с причиной:

```js
// viora-ignore: XSS-001 значение из константы, не пользовательский ввод
```

## Мобильность

- **Ноль зависимостей.** Только стандартная библиотека Python. Ни pip, ни npm, ни докера.
- **Работает офлайн.** Сеть нужна только для `headers` и `deps --online`.
- **Не ломается без Python.** Grep-режим: регулярки — обычный JSON.
- **Переносится копированием.** Папка самодостаточна, путь переопределяется `VIORA_SKILL_DIR`.
- **Идемпотентен.** Повторная установка не плодит дубли, `--uninstall` убирает всё начисто.
- **Не шумит в git.** Рабочие файлы уходят в `.viora/`, установщик сам дописывает `.gitignore`.

## Границы

Честно о том, чего скилл не делает:

- Это **не** замена профессиональному пентесту и не гарантия «код безопасен».
- Сканер — регулярочный, без анализа потока данных. Он находит зацепки; выводы делает агент.
- Никакой атакующей функциональности: только защита, ревью и разбор уязвимостей в вашем коде.
- `deps` без `--online` не ходит в базы уязвимостей — проверяет структуру, пины, скрипты, тайпсквоттинг.
- Динамику (реальные запросы к живому приложению) он не тестирует, кроме команды `headers`.

## FAQ

**Можно поставить сразу на все агенты в одном репозитории?**
Да, `--all`. Все указатели ведут на одну и ту же папку — расхождений между агентами не будет.

**Мешает ли он в обычной работе?**
Нет. В режиме GUARD агент просто пишет безопасный код молча. Развёрнутый разбор — только когда
затронуты чувствительные места или вы попросили проверку.

**Что делать со старым проектом, где находок сотни?**
`baseline` — заморозить текущий долг, дальше гейт валит только новые проблемы. Долг разбирать по
списку, начиная с critical.

**Как обновить?**
Распаковать новую версию и запустить `install.sh` ещё раз. Блоки-указатели заменяются на месте.
